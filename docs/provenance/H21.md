```yaml
Suite ID:        H21
Title:           Speech Uncertainty and SEC Comment Letter Count
Hypothesis:      Does speech uncertainty during earnings calls predict a higher
                 count of SEC EDGAR UPLOAD comment letters received in the
                 subsequent calendar quarter?

Model Family:    PanelOLS (OLS on count DV)
Estimator:       linearmodels.panel.PanelOLS
Unit of Obs:     Call-level (individual earnings call)
Panel Index:     (gvkey, cal_yr) for cols 1-4; (gvkey, cal_yr_qtr) for cols 5-6
Columns:         6
Reference:       --
Runner:          src/f1d/econometric/run_h21_sec_letters.py
```

## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

```
SEC_Letters_fwd_{i,t} = b1*UncAnsCEO
                       + b2*UncPreCEO
                       + b3*UncAnsMgr
                       + b4*UncPreMgr
                       + Controls + alpha_j + gamma_t + epsilon_{i,t}
```

Where:
- `alpha_j` = Industry (FF12) FE (odd columns) or Firm FE (even columns)
- `gamma_t` = Calendar Year FE (cols 1-4) or Calendar Year-Quarter FE (cols 5-6)
- `i` = individual earnings call, `t` = calendar year or calendar year-quarter
- DV is a non-negative integer count estimated via OLS (PanelOLS); Poisson is not used

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| SEC_Letters_fwd | Count of EDGAR UPLOAD letters firm received in next calendar quarter | `count_dict.get((gvkey, _next_cal_qtr(cal_qtr_id)), 0)` where `count_dict` = `{(gvkey, cal_qtr_id): count}` aggregated from UPLOAD-filtered EDGAR filings | EDGAR UPLOAD file + CIK-gvkey map | Lead (Q+1) |

**Construction detail** (from `build_h21_sec_letters_panel.py`, functions `_load_edgar_upload_counts` and `create_sec_letters_dvs`, lines 129-300):
1. Load all EDGAR letters from `inputs/EDGAR_CommentLetters/letters_all.parquet` (columns: cik, form, filing_date).
2. Filter to `form == "UPLOAD"` only (SEC-originated correspondence). CORRESP letters (firm responses) are excluded.
3. Link CIK to gvkey via combined CCM linktable + Compustat direct CIK field (integer CIK comparison to avoid zero-padding issues; CCM preferred, Compustat used for any CIKs not in CCM).
4. Compute `cal_qtr_id = filing_date.dt.year * 10 + filing_date.dt.quarter`.
5. Aggregate to `count_dict = {(gvkey, cal_qtr_id): count}` using `groupby(["gvkey", "cal_qtr_id"]).size()`.
6. For each call at date `d` in calendar quarter `Q`: `SEC_Letters_fwd = count_dict.get((gvkey, Q+1), 0)`. Calls with missing `cal_qtr_id` receive NaN.
7. `SEC_Letters_lag = count_dict.get((gvkey, Q-1), 0)` is also computed (used as `Lagged_DV` in regressions).
8. `_next_cal_qtr` advances a `cal_qtr_id` by one quarter, wrapping Q4 → Q1 of next year (builder lines 113-118).

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| UncAnsCEO | CEO Q&A uncertainty word percentage | (Uncertainty word count / total word count) * 100, CEO Q&A section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| UncPreCEO | CEO presentation uncertainty word percentage | (Uncertainty word count / total word count) * 100, CEO presentation section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| UncAnsMgr | All-manager Q&A uncertainty word percentage | (Uncertainty word count / total word count) * 100, all managers Q&A section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| UncPreMgr | All-manager presentation uncertainty word percentage | (Uncertainty word count / total word count) * 100, all managers presentation section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |

All four IVs are bounded [0, ~2.5] by construction (percentage of Loughran-McDonald uncertainty words). Winsorized per-year 0%/99% (upper-only) at LinguisticEngine level.

### B4. Control Variables

**Base Controls** (cols 1-2):

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| lnAssets | Firm size | ln(atq), atq > 0 only | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + debt_book) / atq | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets | CompustatEngine: iby, atq |
| Leverage | Book leverage | (dlcq + dlttq) / atq, missing debt = 0 | CompustatEngine: dlcq, dlttq, atq |
| Capex | Capital expenditure intensity | capxy_annual (Q4) / atq_lag | CompustatEngine: capxy, atq |
| CashRatio | Cash ratio | cheq / atq | CompustatEngine: cheq, atq |
| DivDummy | Dividend payer indicator | 1 if dvy_annual (Q4) > 0, else 0 | CompustatEngine: dvy |
| sCFO | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of oancfy / atq_{t-1} | CompustatEngine: oancfy, atq |
| Lagged_DV | Lagged SEC letter count | SEC_Letters_lag = count of UPLOAD letters in calendar Q-1 | EDGAR UPLOAD file + CIK-gvkey map |

**Extended Controls** (cols 3-6): Base Controls plus:

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| SalesGrowth | Revenue growth | (saley_t - saley_{t-1}) / abs(saley_{t-1}), Q4 annual | CompustatEngine: saley (saleq fallback) |
| RDSales | R&D intensity | xrdq / atq, missing xrdq = 0 | CompustatEngine: xrdq, atq |
| CashFlowAt | Operating cash flow scaled | oancfy / avg_assets, avg = (atq_t + atq_{t-1})/2 | CompustatEngine: oancfy, atq |
| DailyVola | Stock return volatility | std(daily_ret) * sqrt(252) * 100 over inter-call window | CRSPEngine: daily returns |

**Lagged_DV detail**: In `prepare_regression_data()` (runner line 193), `Lagged_DV` is assigned from `SEC_Letters_lag`, which is the count of EDGAR UPLOAD letters received in the calendar quarter preceding the call (Q-1). This is a single unified row across all specifications.

### B5. Fixed Effects

| FE Type | Column Used | Description | Cols |
|---|---|---|---|
| Industry | ff12_code | Fama-French 12-industry via `other_effects` | 1, 3, 5 |
| Firm | gvkey | Entity FE via `EntityEffects` | 2, 4, 6 |
| Calendar Year | cal_yr | start_date.dt.year via `time_effects=True` | 1, 2, 3, 4 |
| Calendar Year-Quarter | cal_yr_qtr | year*10+quarter via `time_effects=True` | 5, 6 |

Calendar year and year-quarter are derived from the call's `start_date` (not fiscal year). Constructed in `build_cal_yr_qtr_index()` in `panel_utils.py` (lines 195-218): `cal_yr = dt.dt.year`, `cal_yr_qtr = cal_yr * 10 + cal_qtr`.

### B6. Standard Errors and Clustering

- `cov_type="clustered"`, `cluster_entity=True` (runner lines 272, 277)
- Clustering dimension: entity (gvkey) -- firm-clustered standard errors
- No small-sample correction beyond what PanelOLS applies by default

### B7. Hypothesis Test

- Direction: **one-tailed (beta > 0)** -- higher uncertainty predicts more SEC scrutiny (more letters)
- P-value computation (runner lines 303-307):
  ```python
  if not np.isnan(p_two) and not np.isnan(beta):
      p_one = p_two / 2 if beta > 0 else 1 - p_two / 2
  else:
      p_one = np.nan
  ```
- Significance thresholds: `***` p < 0.01, `**` p < 0.05, `*` p < 0.10 (runner lines 320-328, `_sig_stars` function)
- All four IVs share the same one-tailed direction

## F. DATA PIPELINE

### F1. Dependency Chain

1. **Raw inputs**:
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` (112,968 calls)
   - `inputs/EDGAR_CommentLetters/letters_all.parquet` (full EDGAR UPLOAD+CORRESP universe; only UPLOAD kept)
   - `inputs/CRSPCompustat_CCM/CRSPCompustat_CCM.parquet` (CIK-gvkey linkage, preferred source)
   - `inputs/comp_na_daily_all/comp_na_daily_all.parquet` (Compustat CIK field, backup linkage + Compustat controls)
   - Stage 2 linguistic outputs: `outputs/2_Textual_Analysis/2.2_Variables/latest/linguistic_variables_{year}.parquet`
   - CRSP daily stock files (via CRSPEngine, for DailyVola)

2. **Engine loading**:
   - `LinguisticEngine`: loads Stage 2 linguistic variables, applies per-year 0%/99% winsorization (upper-only) to all _pct columns
   - `CompustatEngine`: loads raw Compustat quarterly, computes all accounting controls, applies per-fyearq 1%/99% winsorization
   - `CRSPEngine`: loads CRSP daily returns, computes inter-call DailyVola

3. **Panel builder** (`build_h21_sec_letters_panel.py`):
   - Loads manifest fields (file_name, gvkey, ff12_code, start_date, etc.)
   - Merges 16 builder outputs on `file_name` (left join, row-count-preserving)
   - Attaches `fyearq` via `attach_fyearq()` (merge_asof backward on gvkey+start_date against Compustat datadate)
   - Builds CIK-gvkey map from CCM + Compustat (integer CIK, CCM preferred)
   - Creates `SEC_Letters_fwd` and `SEC_Letters_lag` count DVs via calendar-quarter lookup into `count_dict`
   - Assigns industry sample label (Main/Finance/Utility) via `assign_industry_sample()`
   - Output: `h21_sec_letters_panel.parquet`

4. **Runner loading** (`run_h21_sec_letters.py`):
   - Loads panel parquet from `outputs/variables/h21_sec_letters/latest/h21_sec_letters_panel.parquet`
   - Calls `build_cal_yr_qtr_index()` to create `cal_yr`, `cal_qtr`, `cal_yr_qtr`
   - Filters to main sample (FF12 != 8, 11) via `filter_main_sample()`

5. **Sample filtering** (per spec, in `prepare_regression_data()`):
   - Sets `Lagged_DV = SEC_Letters_lag`
   - Replaces inf/-inf with NaN
   - Drops rows where DV (`SEC_Letters_fwd`) is NaN
   - Complete-case deletion on all required columns
   - Minimum 5 calls per firm filter

6. **Regression estimation**:
   - PanelOLS with entity/industry + time FE
   - Firm-clustered SEs (`cov_type="clustered"`, `cluster_entity=True`)
   - One-tailed p-values computed post-estimation: `p_one = p_two / 2 if beta > 0 else 1 - p_two / 2`

7. **Table generation**:
   - Runner writes its own 6-column LaTeX table (`_save_latex_table`, runner lines 336-459)
   - Also has an entry in `outputs/generate_all_tables.py` for the unified pipeline

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

**Compustat controls**: 1%/99% per fiscal year (fyearq), applied at CompustatEngine level (`_compute_and_winsorize`, `_compustat_engine.py` line 936).
- Applied to: lnAssets, Leverage, TobinsQ, ROA, Capex, CashRatio, RDSales, sCFO, CashFlowAt, SalesGrowth
- NOT applied to: DivDummy (binary), DailyVola (CRSP, not in Compustat engine)

**Linguistic IVs**: 0%/99% per year (upper-only), applied at LinguisticEngine level (`_linguistic_engine.py` line 255).
- Applied to: all four _pct IV columns
- Rationale: lower bound is 0% by construction; only upper tail clipped

**DV (`SEC_Letters_fwd`) and `SEC_Letters_lag`**: Not winsorized (non-negative integer counts; extreme values are real SEC correspondence volumes).

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (runner lines 210-211)
- Inf/-Inf replaced with NaN before regression (runner line 204: `df.replace([np.inf, -np.inf], np.nan)`)
- Missing R&D (xrdq) treated as zero per standard convention (CompustatEngine)
- Missing debt (dlcq, dlttq) treated as zero for Leverage (CompustatEngine)
- `SEC_Letters_fwd` is zero (not NaN) when no letters were received; only NaN when `cal_qtr_id` is NaN (unparseable start_date)

### H3. Transformations

- lnAssets: natural log of total assets (ln(atq))
- DailyVola: annualized (multiply by sqrt(252)) and expressed as percentage (* 100)
- No centering, z-scoring, or other transformations applied to IVs or other controls

## K. MODEL-FAMILY ADDENDUM
------------------------------------------------------------------------

### K1. PanelOLS Specifics

This suite uses PanelOLS as a standard OLS estimator applied to a count DV. The count DV (`SEC_Letters_fwd`) is a non-negative integer; OLS is used rather than Poisson as standard in empirical finance (builder docstring line 17: "PanelOLS (OLS on count DV — standard in empirical finance)").

**Entity effects**:
- Industry FE (odd cols): absorbed via `other_effects=df_panel["ff12_code"]`, `entity_effects=False`, `time_effects=True` (runner lines 263-271)
- Firm FE (even cols): absorbed via `EntityEffects` in PanelOLS formula, `TimeEffects` (runner lines 274-276)
- `drop_absorbed=True` in all specifications (runner lines 269, 276)

## L. KNOWN ISSUES AND NOTES
------------------------------------------------------------------------

1. **Count DV with OLS**: `SEC_Letters_fwd` is a non-negative integer count. The runner uses OLS (PanelOLS) rather than a count model (Poisson, Negative Binomial). The builder docstring explicitly notes this is "standard in empirical finance." The sparsity of the count (6,964/88,205 = 7.9% non-zero in main sample) means predicted values could in principle go negative, though this is not flagged as a problem in the runner. Poisson with FE is not used.

2. **DV differs structurally from H18**: H18 uses a binary DV (`CommentLetter`, any letter in Q+1 = 1/0); H21 uses a count DV (`SEC_Letters_fwd`, number of UPLOAD letters in Q+1). These are related but distinct hypotheses. The two suites use different EDGAR source files: H18 loads `cccl_conversations_all_years.parquet` (a filtered subset of curated CommentLetter events), while H21 loads `inputs/EDGAR_CommentLetters/letters_all.parquet` (the full EDGAR UPLOAD universe, directly filtered). Researchers replicating should be careful not to conflate the two data sources.

3. **Negative Adj R-squared in firm FE specs**: Cols 2, 4, 6 show negative Adj R-squared (-0.024 to -0.026) because the large number of firm fixed effects absorbs degrees of freedom far beyond what the IVs explain within firms. This is expected behavior with rare/sparse count DVs and firm FE, not an error.

4. **No significant results**: All p-values from `model_diagnostics.csv` are substantially above 0.10 for all IVs across all specifications (minimum p_one = 0.12 for UncAnsMgr in col 1). The hypothesis is not supported in this data.

5. **`SEC_Letters_fwd` > 0 attrition row**: The attrition table includes an informational row showing calls with `SEC_Letters_fwd > 0` (6,964) which is not an exclusion step. It is included for context on the event rate. Zero-count observations are retained in regressions.

6. **`fyearq_int` in required columns**: The runner requires `fyearq_int` in the `required` list (line 195) for all specifications, but it is not used in the regression formula. It is carried through as panel metadata. The time FE column is `cal_yr` or `cal_yr_qtr`, not `fyearq_int`.

7. **Integer CIK linkage**: The CIK-gvkey map uses integer CIK comparison to avoid zero-padding discrepancies between EDGAR (which zero-pads CIKs to 10 digits in URLs) and Compustat/CCM (which may store them as plain integers). This is the same design used in H18's `build_cik_gvkey_map()`.

8. **Cal_yr in panel vs. runner**: `cal_yr` and `cal_yr_qtr` are NOT computed in the panel builder; they are computed by the runner after loading the panel, via `build_cal_yr_qtr_index()` (runner line 166). The panel parquet therefore does not contain `cal_yr` or `cal_yr_qtr` columns — these are runtime-computed from `start_date`.
