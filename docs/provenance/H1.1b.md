# Provenance Document: Suite H1.1b

## A. SUITE IDENTITY
------------------------------------------------------------------------

```yaml
Suite ID:        H1.1b
Title:           Binary Product Similarity--Moderated Speech Uncertainty and Cash Holdings
Hypothesis:      Does product-market similarity (Hoberg-Phillips TNIC3TSIMM), binarized
                 at per-fiscal-year median, moderate the Manager QA Uncertainty -> Cash
                 Holdings relationship?
Direction:       Mixed (one-tailed beta > 0 on main IV; two-tailed on interaction and moderator)
Model Family:    PanelOLS
Estimator:       linearmodels.panel.PanelOLS
Unit of Obs:     Call-level (individual earnings call)
Panel Index:     (gvkey, cal_yr) for Col 1; (gvkey, cal_yr_qtr) for Col 2
Columns:         2
Reference:       Hoberg & Phillips (2016)
Runner:          src/f1d/econometric/run_h1_1b_cash_tsimm_binary.py
Panel Builder:   src/f1d/variables/build_h1_cash_holdings_panel.py
```

## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

$$
\text{CashRatio}_{i,t} = \beta_1 \cdot \text{MgrQAUnc\_c}_{i,t}
+ \beta_2 \cdot \text{HighTSIMM}_{i,t}
+ \beta_3 \cdot (\text{MgrQAUnc\_c}_{i,t} \times \text{HighTSIMM}_{i,t})
+ \gamma \cdot \text{Controls}_{i,t}
+ \alpha_{j} + \delta_{t} + \varepsilon_{i,t}
$$

Where:
- $\beta_1$ = effect of uncertainty for low-TSIMM firms (reference group)
- $\beta_1 + \beta_3$ = effect for high-TSIMM firms
- $\beta_3$ = moderation increment (parameter of interest)
- $\alpha_j$ = Fama-French 12 industry FE (via `other_effects`)
- $\delta_t$ = Calendar Year FE (Col 1) or Calendar Year-Quarter FE (Col 2)

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|----------------------|-------------|---------|---------------|--------|
| CashRatio | Cash and equivalents scaled by total assets | cheq / atq | CompustatEngine: cheq, atq | Contemporaneous (t) |

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|----------------------|-------------|---------|---------------|--------|
| Manager_QA_Unc_c | Manager Q&A Uncertainty (mean-centered) | UncAnsMgr - mean(Main sample) | LinguisticEngine | Contemporaneous |
| HighTSIMM | Binary product-market similarity indicator | 1 if TotalSimilarity > per-fiscal-year median (Main sample), else 0 | TNIC3HHIdata.txt (Hoberg-Phillips) | Firm-fiscal-year level |
| MgrQAUnc_x_HighTSIMM | Interaction term | Manager_QA_Unc_c * HighTSIMM | Constructed in runner | Contemporaneous |

**Centering note:** The IV (UncAnsMgr) is mean-centered on the Main sample before forming the interaction to reduce multicollinearity between the moderator and interaction term. The centering mean is computed before complete-case deletion.

**Median-split construction (HighTSIMM):**
1. The raw continuous variable `TotalSimilarity` is loaded from `inputs/TNIC3HHIdata/TNIC3HHIdata.txt`.
2. TNIC data is merged onto the panel by (`gvkey` as integer, `fyearq_int` as fiscal year) via left join.
3. The Main sample mask is applied: `ff12_code not in {8, 11}`.
4. The per-fiscal-year median is computed: `tsimm_main.groupby("fyearq_int")["TotalSimilarity"].median()`.
5. Each observation is compared to its fiscal year's median: `HighTSIMM = (TotalSimilarity > yearly_median).astype(float)`.
6. Observations with NaN `TotalSimilarity` get NaN `HighTSIMM` (dropped in complete-case filter).

Source: `run_h1_1b_cash_tsimm_binary.py`, function `transform_moderator_and_center_iv()`, lines 210-263.

### B4. Control Variables

This suite uses a single extended control block (no separate base/extended distinction):

| Variable Name (code) | Description | Formula | Source Engine |
|----------------------|-------------|---------|---------------|
| Lagged_DV | Lagged dependent variable | CashRatio_lag (previous fiscal year's CashRatio) | Panel builder: create_lag_variable() |
| Leverage | Book leverage | (dlcq + dlttq) / atq; missing debt treated as 0 | CompustatEngine: dlcq, dlttq, atq |
| lnAssets | Firm size | ln(atq); atq <= 0 -> NaN | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (atq + cshoq*prccq - ceqq) / atq | CompustatEngine: atq, cshoq, prccq, ceqq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets | CompustatEngine: iby, atq |
| Capex | Capital expenditure intensity | capxy_annual (Q4) / atq_lag | CompustatEngine: capxy, atq, fqtr |
| DivDummy | Dividend payer indicator | 1 if dvy > 0 (annual, Q4), else 0 | CompustatEngine: dvy, fqtr |
| sCFO | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of oancfy/atq_{t-1} | CompustatEngine: oancfy, atq, fyearq |
| SalesGrowth | Year-over-year revenue growth | (saley_t - saley_{t-1}) / |saley_{t-1}|; Q4-only annual | CompustatEngine: saley (saleq fallback) |
| RDSales | R&D intensity | xrdq / atq; missing xrdq -> 0 | CompustatEngine: xrdq, atq |
| CashFlowAt | Operating cash flow / assets | oancfy / avg_assets; avg = (atq_t + atq_{t-1})/2 | CompustatEngine: oancfy, atq |
| DailyVola | Stock return volatility | std(daily_ret) * sqrt(252) * 100 over inter-call window | CRSPEngine: daily returns |

**Lagged_DV construction:** `CashRatio_lag` is created in the panel builder (`create_lag_variable()`, lines 379-447 of `build_h1_cash_holdings_panel.py`). For each firm-fiscal-year, it takes the end-of-year CashRatio (from the latest call in that fiscal year) and shifts +1 within gvkey. Valid only if fiscal years are consecutive (gap years -> NaN). In the runner, `panel["Lagged_DV"] = panel["CashRatio_lag"]` (line 295).

### B5. Fixed Effects

| FE Type | Column Used | Description | Specification |
|---------|-------------|-------------|---------------|
| Industry | ff12_code | Fama-French 12 industry FE (via `other_effects` parameter) | Both Cols 1-2 |
| Time (Col 1) | cal_yr | Calendar Year FE (absorbed via `time_effects=True`) | Col 1 only |
| Time (Col 2) | cal_yr_qtr | Calendar Year-Quarter FE (absorbed via `time_effects=True`) | Col 2 only |

`cal_yr` and `cal_yr_qtr` are derived from `start_date` (call date) via `build_cal_yr_qtr_index()`:
- `cal_yr = start_date.dt.year`
- `cal_yr_qtr = cal_yr * 10 + cal_qtr` (e.g., 20103 = 2010 Q3)

Source: `panel_utils.py`, function `build_cal_yr_qtr_index()`, lines 195-218.

### B7. Hypothesis Test

| Variable | Direction | P-value Computation | Significance Thresholds |
|----------|-----------|---------------------|------------------------|
| Manager_QA_Unc_c (main IV) | One-tailed (beta > 0) | `p_one = p_two / 2` if beta > 0, else `1 - p_two / 2` | \*p<0.10, \*\*p<0.05, \*\*\*p<0.01 |
| HighTSIMM (moderator) | Two-tailed | Direct from PanelOLS `pvalues` | \*p<0.10, \*\*p<0.05, \*\*\*p<0.01 |
| MgrQAUnc_x_HighTSIMM (interaction) | Two-tailed | Direct from PanelOLS `pvalues` | \*p<0.10, \*\*p<0.05, \*\*\*p<0.01 |

Source: `run_h1_1b_cash_tsimm_binary.py`, lines 391-394 (one-tailed IV), lines 400-402 (two-tailed interaction), lines 404-405 (stars functions).

## F. DATA PIPELINE
------------------------------------------------------------------------

### F1. Dependency Chain

1. **Raw inputs:**
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` (call manifest)
   - `inputs/comp_na_daily_all/comp_na_daily_all.parquet` (Compustat quarterly)
   - `inputs/CRSP_DSF/CRSP_DSF_{year}_Q{q}.parquet` (CRSP daily stock files)
   - `outputs/2_Textual_Analysis/2.2_Variables/latest/linguistic_variables_{year}.parquet` (linguistic variables)
   - `inputs/TNIC3HHIdata/TNIC3HHIdata.txt` (Hoberg-Phillips TNIC3 data)

2. **Engine loading:**
   - CompustatEngine (singleton): loads raw Compustat, computes all accounting variables, winsorizes 1%/99% by fiscal year
   - CRSPEngine (singleton): loads CRSP daily returns, computes DailyVola
   - LinguisticEngine (singleton): loads Stage 2 linguistic variables, winsorizes 0%/99% per year (upper-only)

3. **Panel builder (Stage 3):**
   - Load manifest (base DataFrame)
   - Build all variables via individual builders (each calls shared engine)
   - Merge all onto manifest by `file_name` (left join, zero row-delta enforced)
   - Attach `fyearq` via `attach_fyearq()` (merge_asof from Compustat datadate)
   - Compute `CashRatio_lead` (fiscal year t+1 end-of-year CashRatio)
   - Compute `CashRatio_lag` (fiscal year t-1 end-of-year CashRatio)
   - Assign industry sample (Main/Finance/Utility via ff12_code)
   - Save `h1_cash_holdings_panel.parquet`

4. **Runner loading (Stage 4):**
   - Load H1 panel (selected columns only)
   - Build `cal_yr_qtr` index from `start_date`
   - Merge TNIC3TSIMM from TNIC3HHIdata.txt by (gvkey as integer, fyearq_int)
   - Compute HighTSIMM (per-fiscal-year median split on Main sample)
   - Center IV on Main sample mean
   - Filter to Main sample (exclude ff12 = 8, 11)

5. **Sample filtering (per spec):**
   - Create `Lagged_DV = CashRatio_lag`
   - Create interaction term: `MgrQAUnc_x_HighTSIMM = Manager_QA_Unc_c * HighTSIMM`
   - Replace inf/-inf with NaN
   - Drop DV-missing rows
   - Complete-case deletion (all required columns non-NaN)
   - Drop firms with < 5 calls

6. **Regression estimation:**
   - PanelOLS with `entity_effects=False`, `time_effects=True`, `other_effects=df["ff12_code"]`, `drop_absorbed=True`
   - Firm-clustered SEs
   - 2 model specifications (varying time FE)

7. **Table generation:**
   - H1.1b has an entry in `outputs/generate_all_tables.py` (type="moderation", cols=2).
     The runner also directly writes a LaTeX table via `_save_latex_table()` (lines 462-581)
     for standalone use. The generate_all_tables.py entry references run directory
     "h1_1b_cash_tsimm_binary/2026-03-31_155928" and uses the moderation table generator
     with key_tails=["one_pos","two","two"].

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

**Compustat variables:** 1%/99% by fiscal year (fyearq), applied at CompustatEngine level in `_compute_and_winsorize()`.

Applied to: CashRatio, Leverage, lnAssets, TobinsQ, ROA, Capex, sCFO, RDSales.

Separately winsorized in Biddle engine (also 1%/99% by fiscal year): SalesGrowth, CashFlowAt.

NOT winsorized (Compustat): DivDummy (binary).

**Linguistic variables:** 0%/99% per calendar year (upper-only), applied at LinguisticEngine level. Applied to: UncAnsMgr.

**CRSP variables:** DailyVola is not winsorized (bounded by construction via min 10 trading days requirement).

**TNIC variables:** TotalSimilarity is not winsorized (external Hoberg-Phillips data). HighTSIMM is binary (0/1).

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable (DV, IV, moderator, interaction, controls, FE identifiers) is NaN.
- Inf/-Inf replaced with NaN before regression (`df.replace([np.inf, -np.inf], np.nan)`, line 304).
- Firms with < 5 calls after complete-case deletion are dropped.

### H3. Transformations

| Variable | Transformation | Description |
|----------|---------------|-------------|
| UncAnsMgr | Mean-centering | Subtract Main sample mean before interaction |
| TotalSimilarity | Median split | Binary: above/below per-fiscal-year median (Main sample) |
| lnAssets | Natural log | ln(atq) |
| MgrQAUnc_x_HighTSIMM | Multiplication | Manager_QA_Unc_c * HighTSIMM |

## K. MODEL-FAMILY ADDENDUM
------------------------------------------------------------------------

### K1. PanelOLS Specifics

- **Entity effects:** `entity_effects=False` -- NO firm FE absorbed. Industry FE is used instead via `other_effects`.

## L. KNOWN ISSUES AND NOTES
------------------------------------------------------------------------

1. **CurrentRatio built but unused:** The panel builder constructs `CurrentRatio` (actq / lctq) via `CurrentRatioBuilder`, but it is NOT included in the `CONTROLS` list of this runner. It is present in the parquet panel but excluded from regressions.

2. **Additional linguistic variables built but unused:** The panel builder also loads `UncAnsCEO`, `UncPreCEO`, `UncPreMgr`, `Analyst_QA_Uncertainty`, and `NegativeSentiment`. These are present in the H1 panel for use by other H1-family suites but are not used in H1.1b (which only uses `UncAnsMgr`).

3. **CashRatio_lead built but unused:** The panel builder computes `CashRatio_lead` (t+1 fiscal year CashRatio), but H1.1b uses contemporaneous `CashRatio` as the DV, not the lead. The lead variable is used by other H1-family suites (e.g., H1 base).

4. **TNIC merge at runner level, not panel builder:** Unlike most variables that are merged in the panel builder (Stage 3), the TNIC3TSIMM data is loaded and merged directly in the runner (Stage 4). This means the H1 panel parquet does not contain TNIC data; it is only available at regression time for suites that load it.

5. **Median split computed before complete-case deletion:** The per-fiscal-year median for the HighTSIMM split and the IV centering mean are computed on the Main sample before complete-case deletion and the min-calls filter. This is the standard approach (moderator construction should not depend on which observations have complete data on all controls).

6. **Binary moderator repeated across calls:** HighTSIMM is a firm-fiscal-year level variable. All calls from the same firm in the same fiscal year share the same HighTSIMM value. This is noted in the LaTeX table footnotes (line 577).

7. **R-squared computation:** The runner manually computes Adj R-squared as `1 - (1 - R2) * (nobs - 1) / df_resid` (lines 407, 420). This is the standard formula applied to the overall R-squared from PanelOLS (not within-R-squared).
