## A. SUITE IDENTITY
------------------------------------------------------------------------

```yaml
Suite ID:        H13
Title:           Speech Uncertainty and Capital Expenditure
Hypothesis:      Does managerial linguistic uncertainty during earnings calls affect
                 contemporaneous and future capital expenditure intensity?
Direction:       two-tailed (beta != 0, no directional prediction)
Model Family:    PanelOLS
Estimator:       linearmodels.panel.PanelOLS
Unit of Obs:     call-level (one row per earnings call)
Panel Index:     (gvkey, cal_yr) or (gvkey, cal_yr_qtr) depending on spec
Columns:         12
Reference:       --
Runner:          src/f1d/econometric/run_h13_capex.py
Panel Builder:   src/f1d/variables/build_h13_capex_panel.py
```

## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

$$
\text{CapexAt}_{i,t} = \beta_1 \cdot \text{CEO\_QA\_Uncertainty\_pct} + \beta_2 \cdot \text{CEO\_Pres\_Uncertainty\_pct} + \beta_3 \cdot \text{Manager\_QA\_Uncertainty\_pct} + \beta_4 \cdot \text{Manager\_Pres\_Uncertainty\_pct} + \gamma' \mathbf{Controls} + \alpha_i + \delta_t + \varepsilon_{i,t}
$$

Where $\alpha_i$ is entity FE (firm or industry) and $\delta_t$ is time FE (calendar year or calendar year-quarter). The same equation applies with $\text{CapexAt\_lead}_{i,t+1}$ as the DV in columns 7--12.

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|----------------------|-------------|---------|---------------|--------|
| CapexAt | Capital expenditure intensity (contemporaneous) | capxy (Q4 annual) / atq (lagged annual, t-1) | CompustatEngine: capxy, atq | Contemporaneous (t) |
| CapexAt_lead | Capital expenditure intensity (lead) | CapexAt for fiscal year t+1, matched via (gvkey, fyearq_int) | CompustatEngine via panel builder lead construction | Lead (t+1) |

### B3. Independent Variable(s)

All 4 IVs enter every model simultaneously (not one at a time).

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|----------------------|-------------|---------|---------------|--------|
| CEO_QA_Uncertainty_pct | CEO Q&A uncertainty word percentage | (uncertainty word count / total word count) * 100 for CEO Q&A section | LinguisticEngine | Contemporaneous (t) |
| CEO_Pres_Uncertainty_pct | CEO presentation uncertainty word percentage | (uncertainty word count / total word count) * 100 for CEO presentation section | LinguisticEngine | Contemporaneous (t) |
| Manager_QA_Uncertainty_pct | Manager Q&A uncertainty word percentage | (uncertainty word count / total word count) * 100 for all managers Q&A section | LinguisticEngine | Contemporaneous (t) |
| Manager_Pres_Uncertainty_pct | Manager presentation uncertainty word percentage | (uncertainty word count / total word count) * 100 for all managers presentation section | LinguisticEngine | Contemporaneous (t) |

No centering, log-transform, or z-scoring is applied to IVs.

### B4. Control Variables

**Base Controls (8 variables):**

| Variable Name (code) | Description | Formula | Source Engine |
|----------------------|-------------|---------|---------------|
| Size | Firm size | ln(atq), requires atq > 0 | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + dlcq + dlttq) / atq | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby (Q4 annual) / avg_assets, where avg_assets = (atq_t + atq_{t-1}) / 2 | CompustatEngine: iby, atq |
| BookLev | Book leverage | (dlcq + dlttq) / atq; missing debt treated as zero | CompustatEngine: dlcq, dlttq, atq |
| CashHoldings | Cash holdings ratio | cheq / atq | CompustatEngine: cheq, atq |
| DividendPayer | Dividend payer indicator | 1 if dvy (Q4 annual) > 0, else 0 | CompustatEngine: dvy |
| OCF_Volatility | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of (oancfy / atq_{t-1}) per gvkey | CompustatEngine: oancfy, atq |
| Lagged_DV | Lagged dependent variable | CapexAt_lag (fiscal year t-1 CapexAt) when DV is CapexAt or CapexAt_lead | Panel builder: CapexAt_lag via (gvkey, fyearq_int) |

Note on Lagged_DV: `Lagged_DV` is dynamically assigned in `prepare_regression_data()` (runner line 252--255). The base DV name is extracted by stripping `_lead` from the DV name, then `_lag` is appended. For all 12 specs in H13, Lagged_DV = `CapexAt_lag`. CapexAt is NOT included as a separate control because it IS the DV.

**Extended Controls (Base + 4 = 12 variables):**

| Variable Name (code) | Description | Formula | Source Engine |
|----------------------|-------------|---------|---------------|
| SalesGrowth | Year-over-year revenue growth | (saley_t - saley_{t-1}) / abs(saley_{t-1}); Q4 annual panel; saleq fallback | CompustatEngine: saley, saleq |
| RD_Intensity | R&D intensity | xrdq / atq; missing xrdq treated as zero | CompustatEngine: xrdq, atq |
| CashFlow | Operating cash flow ratio | oancfy / avg_assets, where avg_assets = (atq_t + atq_{t-1}) / 2 | CompustatEngine: oancfy, atq |
| Volatility | Stock return volatility | std(daily_ret) * sqrt(252) * 100 over inter-call window [prev_call+5d, call-5d], min 10 trading days | CRSPEngine: daily RET |

### B5. Fixed Effects

| FE Type | Column Used | Description |
|---------|-------------|-------------|
| Entity (industry specs) | ff12_code | Fama-French 12 industry FE, absorbed via PanelOLS `other_effects` parameter |
| Entity (firm specs) | gvkey | Firm FE, absorbed via PanelOLS `EntityEffects` |
| Time (Year specs) | cal_yr | Calendar year FE, absorbed via PanelOLS `time_effects=True` or `TimeEffects` in formula |
| Time (Year-Quarter specs) | cal_yr_qtr | Calendar year-quarter FE (e.g., 20103 = 2010 Q3), absorbed via PanelOLS `time_effects=True` or `TimeEffects` |

`cal_yr` and `cal_yr_qtr` are derived from start_date (the call date), NOT from Compustat fiscal year. Construction: `cal_yr = start_date.dt.year`, `cal_yr_qtr = cal_yr * 10 + start_date.dt.quarter`.
Source: `build_cal_yr_qtr_index()` in `src/f1d/shared/variables/panel_utils.py`, lines 195--218.

### B6. Standard Errors and Clustering

- **cov_type:** `"clustered"`
- **Clustering dimension:** Entity (firm) -- `cluster_entity=True`
- **Code reference:** runner line 359 (industry specs), line 365 (firm specs)
- **Small-sample corrections:** Default PanelOLS clustered SE corrections apply

### B7. Hypothesis Test

- **Direction:** Two-tailed (beta != 0) -- no directional prediction for H13
- **P-value computation:** Two-tailed p-values used directly from PanelOLS (`model.pvalues`); no one-tailed conversion
- **Significance thresholds:** `***` p < 0.01, `**` p < 0.05, `*` p < 0.10
- **Code reference:** `_sig_stars()` at runner lines 411--420; two-tailed p-values stored as `{iv}_p_two` in metadata (runner line 392)

The attrition cascade is implemented across both the panel builder and the runner. Row counts are runtime-dependent [UNVERIFIED -- see `sample_attrition.csv` in the latest Stage 4 output for exact counts]. The structure is:

| Step | Filter | Applied In | Description |
|------|--------|-----------|-------------|

Note: Steps 3--6 are applied per-specification because each spec may have a different DV and different required columns. Columns 7--12 (CapexAt_lead) will have fewer observations than columns 1--6 because the lead is NaN for the last fiscal year per firm and for fiscal year gaps.

## F. DATA PIPELINE
------------------------------------------------------------------------

### F1. Dependency Chain

1. **Raw inputs:**
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` (call manifest with file_name, gvkey, ff12_code, start_date)
   - `outputs/2_Textual_Analysis/2.2_Variables/latest/linguistic_variables_{year}.parquet` (year-partitioned linguistic variables)
   - Compustat quarterly raw data (loaded by CompustatEngine)
   - CRSP daily stock files (loaded by CRSPEngine)

2. **Engine loading:**
   - CompustatEngine (singleton): loads Compustat quarterly data, computes all financial variables (Size, TobinsQ, ROA, BookLev, CashHoldings, CapexAt, DividendPayer, OCF_Volatility, SalesGrowth, RD_Intensity, CashFlow), applies 1%/99% per-fiscal-year winsorization, matches to manifest via merge_asof on (gvkey, start_date -> datadate)
   - LinguisticEngine (singleton): loads Stage 2 linguistic parquets, applies 0%/99% upper-only per-year winsorization to all _pct columns, returns by file_name
   - CRSPEngine (singleton): loads CRSP daily files, computes Volatility per call from inter-call daily returns

3. **Panel builder** (`build_h13_capex_panel.py`):
   - Load manifest fields + all 14 variable builders
   - Merge all onto manifest by `file_name` (left join, zero-row-delta enforced)
   - Attach `fyearq` via `attach_fyearq()` (merge_asof on gvkey/start_date to Compustat datadate)
   - Compute `CapexAt_lead` via `create_capex_lead()`: group by (gvkey, fyearq_int), take latest call per fiscal year, shift -1, validate consecutive fiscal years
   - Compute `CapexAt_lag` via `create_capex_lag()`: same pattern but shift +1
   - Assign industry sample (Main/Finance/Utility) via `assign_industry_sample()`
   - Save `h13_capex_panel.parquet`

4. **Runner loading** (`run_h13_capex.py`):
   - Load panel parquet with explicit column list (line 206--218)
   - Build `cal_yr_qtr` index via `build_cal_yr_qtr_index()`

5. **Sample filtering:**
   - Filter to Main sample (exclude FF12=8,11)
   - Per-spec: drop NaN DV, complete-case filter, min 5 calls per firm

6. **Regression estimation:**
   - PanelOLS with firm-clustered SEs
   - 12 specifications (see Section C)
   - Two-tailed p-values

7. **Table generation:**
   - Runner writes its own LaTeX table (`_save_latex_table()`)
   - Entry in `outputs/generate_all_tables.py` for unified table generation

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

**Compustat financial variables:**
- Level: 1%/99% by fiscal year (fyearq), applied within `_compute_and_winsorize()` in CompustatEngine
- Applied to: Size, TobinsQ, ROA, BookLev, CashHoldings, CapexAt, OCF_Volatility, RD_Intensity
- Additionally: SalesGrowth and CashFlow are winsorized 1%/99% by fiscal year inside `_compute_biddle_residual()` (not double-winsorized)
- Skipped: DividendPayer (binary), fqtr (identifier)
- Minimum observations per year-group: 10 (below threshold: year left unchanged)

**Linguistic IVs:**
- Level: 0%/99% upper-only per calendar year
- Applied to: all _pct columns (CEO_QA_Uncertainty_pct, CEO_Pres_Uncertainty_pct, Manager_QA_Uncertainty_pct, Manager_Pres_Uncertainty_pct)
- Bounded [0, 100] by construction; lower bound clipped at 0% (no lower tail trimming)

**CRSP Volatility:**
- Not winsorized in the Compustat engine winsorization loop (computed by CRSPEngine separately)

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (runner line 282)
- Inf/-Inf replaced with NaN before regression (runner line 268: `df.replace([np.inf, -np.inf], np.nan)`)
- CapexAt_lead is NaN for last fiscal year per firm and for non-consecutive fiscal year gaps
- CapexAt_lag is NaN for first fiscal year per firm and for non-consecutive fiscal year gaps

### H3. Transformations

| Variable | Transformation |
|----------|---------------|
| Size | Natural log of atq |
| Volatility | Annualized: std(daily_ret) * sqrt(252) * 100 |

No centering, z-scoring, or additional scaling is applied to any variable.
