# Provenance Document: H5

------------------------------------------------------------------------
## A. SUITE IDENTITY
------------------------------------------------------------------------

```yaml
Suite ID:        H5
Title:           H5: Speech Uncertainty and Analyst Forecast Dispersion (Wang 2020)
Hypothesis:      Higher managerial uncertainty language during earnings calls leads to greater
                 analyst forecast dispersion, measured as the price-scaled standard deviation of
                 individual analyst EPS forecasts in the pre-announcement window.
Direction:       One-tailed (beta > 0)
Model Family:    PanelOLS
Estimator:       linearmodels.panel.PanelOLS
Unit of Obs:     Call-level (individual earnings call)
Panel Index:     (gvkey, cal_yr) for Calendar Year FE specs; (gvkey, cal_yr_qtr) for Year-Quarter FE specs
Columns:         12
Reference:       Wang (2020, Review of Accounting and Finance 19(3): 289-312)
Runner:          src/f1d/econometric/run_h5b_wang_disp.py
Panel Builder:   src/f1d/variables/build_h5b_wang_disp_panel.py
```

## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

```
DISP_{i,t} = b1*UncAnsCEO + b2*UncPreCEO
               + b3*UncAnsMgr + b4*UncPreMgr
               + Controls + alpha_i + gamma_t + epsilon_{i,t}
```

Where `alpha_i` is entity FE (Industry FF12 or Firm) and `gamma_t` is time FE (Calendar Year or Calendar Year-Quarter).

For lead specifications (cols 7-12), the DV is `DISP_lead` (next fiscal quarter's DISP).

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| DISP | Price-scaled analyst forecast dispersion | SD(latest analyst EPS forecasts in T-31..T-1 window) / prccq_prior | IbesDetailEngine + CompustatEngine (prccq) | Contemporaneous (t) |
| DISP_lead | Next fiscal quarter's DISP | DISP shifted forward by one consecutive fiscal quarter per gvkey | Same as DISP, fiscal quarter shifted | Lead (t+1 quarter) |

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| UncAnsCEO | CEO Q&A uncertainty word percentage | (uncertainty word count in CEO Q&A turns / total word count in CEO Q&A turns) * 100 | LinguisticEngine (Stage 2 outputs) | Contemporaneous |
| UncPreCEO | CEO presentation uncertainty word percentage | (uncertainty word count in CEO presentation turns / total word count in CEO presentation turns) * 100 | LinguisticEngine (Stage 2 outputs) | Contemporaneous |
| UncAnsMgr | All-manager Q&A uncertainty word percentage | (uncertainty word count in all-manager Q&A turns / total word count in all-manager Q&A turns) * 100 | LinguisticEngine (Stage 2 outputs) | Contemporaneous |
| UncPreMgr | All-manager presentation uncertainty word percentage | (uncertainty word count in all-manager presentation turns / total word count in all-manager presentation turns) * 100 | LinguisticEngine (Stage 2 outputs) | Contemporaneous |

No centering, log-transform, or z-scoring is applied to IVs.

### B4. Control Variables

**Base Controls:**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| lnAssets | Firm size | ln(atq), atq > 0 only | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + dlcq + dlttq) / atq | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg(atq_t, atq_{t-1}) | CompustatEngine: iby, atq |
| Leverage | Book leverage | (dlcq + dlttq) / atq, missing debt filled as 0 | CompustatEngine: dlcq, dlttq, atq |
| Capex | Capital expenditure intensity | capxy_annual (Q4) / atq_lag_annual | CompustatEngine: capxy, atq |
| DivDummy | Dividend payer dummy | 1 if dvy_annual (Q4) > 0, else 0 | CompustatEngine: dvy |
| sCFO | Operating cash flow volatility | Rolling 5-year std (min 3 years) of oancfy / atq_{t-1} per gvkey | CompustatEngine: oancfy, atq |
| DISP_lag | Lagged DV (prior quarter dispersion) | DISP shifted backward by one consecutive fiscal quarter per gvkey | IbesDetailEngine + CompustatEngine |

**Extended Controls (Base + the following):**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| SurpDec | Earnings surprise decile | (ACTUAL - MEANEST) ranked into -5..+5 scale within calendar quarter | IbesEngine (Summary consensus) |
| Loss | Loss indicator | 1 if ibq < 0, else 0 | CompustatEngine: ibq |
| UncQue | Analyst Q&A uncertainty word percentage | (uncertainty word count in analyst Q&A turns / total word count in analyst Q&A turns) * 100 | LinguisticEngine (Stage 2 outputs) |
| NegCall | Negative sentiment, entire call | (negative word count in entire call / total word count in entire call) * 100 | LinguisticEngine (Stage 2 outputs) |

DISP_lag serves as the lagged DV control for all specifications. It is included in BASE_CONTROLS and therefore appears in all 12 columns.

### B5. Fixed Effects

| FE Type | Column Used | Description | Specs |
|---|---|---|---|
| Industry | ff12_code (via `other_effects`) | Fama-French 12-industry classification | Cols 1, 3, 5, 7, 9, 11 (odd) |
| Firm | gvkey (via `EntityEffects`) | Firm fixed effects (absorbed) | Cols 2, 4, 6, 8, 10, 12 (even) |
| Calendar Year | cal_yr (via `TimeEffects`, panel index) | Calendar year from start_date | Cols 1-4, 7-10 |
| Calendar Year-Quarter | cal_yr_qtr (via `TimeEffects`, panel index) | Calendar year-quarter (YYYY*10 + Q) from start_date | Cols 5-6, 11-12 |

Source: Runner lines 242-250. `cal_yr` is derived from `start_date.dt.year` in `build_cal_yr_qtr_index()` (panel_utils.py line 215). `cal_yr_qtr` is `cal_yr * 10 + cal_qtr` where `cal_qtr = start_date.dt.quarter` (panel_utils.py line 217).

### B6. Standard Errors and Clustering

- **cov_type**: `"clustered"` (runner line 263 and 268)
- **Clustering dimension**: Entity only (`cluster_entity=True`)
- **Small-sample corrections**: None explicitly specified (linearmodels default)

### B7. Hypothesis Test

- **Direction**: One-tailed (beta > 0). Higher uncertainty language predicts higher analyst forecast dispersion.
- **P-value computation**: `p_one = p_two / 2` if `beta > 0`, else `p_one = 1 - p_two / 2` (runner line 287).
- **Significance thresholds**: `***` p < 0.01, `**` p < 0.05, `*` p < 0.10 (runner line 291).

## F. DATA PIPELINE
------------------------------------------------------------------------

### F1. Dependency Chain

1. **Raw inputs**:
   - `inputs/tr_ibes/tr_ibes_{YYYY}.parquet` -- IBES Detail yearly files (individual analyst estimates)
   - `inputs/CRSPCompustat_CCM/CRSPCompustat_CCM.parquet` -- CCM linking table (CUSIP8 to GVKEY)
   - Compustat quarterly data (loaded via CompustatEngine)
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` -- call-level manifest
   - `outputs/2_Textual_Analysis/2.2_Variables/latest/` -- Stage 2 linguistic variable parquet files

2. **Engine loading**:
   - `IbesDetailEngine`: loads yearly IBES Detail parquets, filters to MEASURE=EPS, FPI=[6,7], PDF=D, links CUSIP8 to GVKEY via CCM
   - `CompustatEngine`: loads Compustat quarterly, computes all financial controls, winsorizes 1%/99% per year, matches to call dates via merge_asof backward
   - `LinguisticEngine`: loads Stage 2 linguistic variable parquets, winsorizes 0%/99% per year (upper-only)
   - `IbesEngine` (Summary): loads IBES consensus data for SurpDec computation

3. **Panel builder** (`build_h5b_wang_disp_panel.py`):
   - Starts from manifest (112,968 rows)
   - Merges 15 builder outputs on `file_name` (left join)
   - Assigns `sample` (Main/Finance/Utility) via `assign_industry_sample(ff12_code)`
   - Attaches `fyearq` via `attach_fyearq()` (merge_asof backward to Compustat datadate)
   - Creates lead/lag via fiscal quarter shifting in `create_lead_lag_variables()`
   - Outputs: `h5b_wang_disp_panel.parquet`

4. **Runner loading** (`run_h5b_wang_disp.py`):
   - Loads panel parquet from latest Stage 3 output
   - Builds `cal_yr_qtr` index via `build_cal_yr_qtr_index()` (from start_date)
   - Sets panel index to `(gvkey, cal_yr)` or `(gvkey, cal_yr_qtr)` depending on spec

5. **Sample filtering** (per spec):
   - Exclude FF12=8 (Utility) and FF12=11 (Finance) -- `filter_main_sample()`
   - Replace inf/-inf with NaN
   - Drop rows where DV is NaN
   - Drop rows where any required variable is NaN (complete case)
   - Drop firms with < 5 calls

6. **Regression estimation**:
   - PanelOLS for each of 12 specs
   - For industry FE: `entity_effects=False, time_effects=True, other_effects=ff12_code`
   - For firm FE: formula-based `EntityEffects + TimeEffects`
   - `cov_type="clustered", cluster_entity=True`
   - One-tailed p-values computed from two-tailed

7. **Table generation**:
   - `outputs/generate_all_tables.py` has entry `"id": "H5"` at line 152
   - Uses standard 4-IV suite generator with `tail="one"`, `hyp_dir=">"`

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

**Compustat-sourced controls** (lnAssets, Leverage, ROA, TobinsQ, Capex, sCFO):
- Level: 1%/99% per fiscal year (`_winsorize_by_year()` in `_compustat_engine.py`)
- Applied at CompustatEngine level before any merge to call panel
- Minimum 10 observations per year group required for winsorization
- DivDummy exempt (binary), Loss exempt (binary)

**Linguistic IVs and controls** (all `_pct` columns):
- Level: 0%/99% per calendar year (upper-only; lower bound is natural 0)
- Applied at LinguisticEngine level (`_linguistic_engine.py` lines 255-258)
- These variables are bounded [0, 100] by construction

**DISP**:
- Level: 1%/99% pooled (all years together)
- Applied within WangDispBuilder (`wang_disp.py` lines 85-89)
- Note: This is pooled, not per-year, following Wang (2020) implementation

**SurpDec**:
- Not winsorized (discrete ranked variable, range -5 to +5)

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (`prepare_regression_data()`, runner line 201-203)
- Inf/-Inf replaced with NaN before complete-case filter (runner line 195)
- DISP requires >= 2 analysts in T-31..T-1 window AND valid prccq_prior > 0; otherwise NaN

### H3. Transformations

- **lnAssets**: natural log of atq (only for atq > 0)
- No other log, z-score, centering, or scaling applied to variables in this suite

1. **Output directory**: The `dir` path in `generate_all_tables.py` now points to `h5b_wang_disp/2026-03-31_140307`, which is the 12-column run produced after the YQ-FE migration. This issue is resolved.

2. **Stale FE label in output files**: The col 1 regression output text file (`regression_results_col1.txt` line 4) says `"FE: industry + Fiscal Year"`, but the code now uses `cal_yr` (calendar year). This label comes from the `save_outputs()` function in the runner. The actual `time_col` assignment at line 242 is `"cal_yr_qtr" if fe_type.endswith("_yq") else "cal_yr"` (calendar, not fiscal). The stale label in the output text was written by the old runner before the FE migration. The code is truth; the output text is stale.

3. **DISP pooled winsorization**: Unlike Compustat controls (winsorized per fiscal year) and linguistic variables (per calendar year), DISP is winsorized at 1%/99% pooled across all years. This is per the Wang (2020) implementation but is a methodological difference from the rest of the pipeline.

4. **IBES Detail FPI=[6,7] logic**: The IbesDetailEngine uses `fpi_valid = ['6', '7']` where FPI 6 = current quarter, FPI 7 = next quarter. Both are needed because FPI is relative to the estimate date, not the call date. The WangDispBuilder matches calls to target FPEDATS via forward merge_asof with 120-day tolerance, then filters estimates to the T-31..T-1 window.

5. **Lead/lag consecutive quarter validation**: The `create_lead_lag_variables()` function validates that lead and lag quarters are truly consecutive (e.g., Q4 of year Y is followed by Q1 of year Y+1). Non-consecutive quarters produce NaN. This is why DISP_lead has lower coverage (13,587 vs 17,089 observations in base controls).

6. **Panel index uses fyearq_int in load_panel columns**: The runner's `load_panel()` function requests `fyearq_int` at line 154, but the actual regression panel index uses `cal_yr` or `cal_yr_qtr` (line 250). `fyearq_int` is loaded but only used in `prepare_regression_data()` as part of the `required` list (line 186), meaning it serves as a complete-case filter column rather than the FE time index.

7. **SurpDec and Loss are not in SUMMARY_STATS_VARS**: These two extended controls are used in regressions but are excluded from the summary statistics output table (runner lines 101-116).
