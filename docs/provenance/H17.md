## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

**Contemporaneous (cols 1-6):**

$$
\text{RepurchaseIntensity}_{i,t} = \beta_1 \cdot \text{CEO\_QA\_Uncertainty\_pct} + \beta_2 \cdot \text{CEO\_Pres\_Uncertainty\_pct} + \beta_3 \cdot \text{Manager\_QA\_Uncertainty\_pct} + \beta_4 \cdot \text{Manager\_Pres\_Uncertainty\_pct} + \gamma' \mathbf{Controls} + \alpha_i + \delta_t + \varepsilon_{i,t}
$$

**Lead (cols 7-12):**

$$
\text{RepurchaseIntensity\_lead\_qtr}_{i,t} = \beta_1 \cdot \text{CEO\_QA\_Uncertainty\_pct} + \beta_2 \cdot \text{CEO\_Pres\_Uncertainty\_pct} + \beta_3 \cdot \text{Manager\_QA\_Uncertainty\_pct} + \beta_4 \cdot \text{Manager\_Pres\_Uncertainty\_pct} + \gamma' \mathbf{Controls} + \alpha_i + \delta_t + \varepsilon_{i,t}
$$

Where $\alpha_i$ is entity FE (Industry FF12 or Firm) and $\delta_t$ is time FE (Calendar Year or Calendar Year-Quarter).

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| RepurchaseIntensity | Quarterly share repurchase intensity | quarterly_prstkcy / atq_{t-1} (de-cumulated YTD prstkcy divided by previous quarter's total assets) | CompustatEngine: prstkcy, atq, fqtr, fyearq | Contemporaneous (t) |
| RepurchaseIntensity_lead_qtr | Next fiscal quarter's RepurchaseIntensity | Shift RepurchaseIntensity forward by one consecutive fiscal quarter within firm | Derived from RepurchaseIntensity via fiscal_qtr_id shifting in panel builder | Lead (t+1 quarter) |

**De-cumulation logic (CompustatEngine, lines 1040-1087):**

1. Compustat `prstkcy` (Purchase of Common and Preferred Stock) is reported as **YTD cumulative** within each fiscal year.
2. **Q1**: quarterly_repurchases = prstkcy (Q1 is the first quarter; the YTD value equals the quarter itself). Missing prstkcy is filled with 0.
3. **Q2-Q4**: quarterly_repurchases = prstkcy - prstkcy_{prev_quarter}, only when both the current and previous quarter's prstkcy are non-missing AND both rows fall within the same fiscal year (fyearq == prev_fyearq). Otherwise NaN.
4. **Negative clamp**: quarterly_repurchases are clipped to 0 (negatives arise from restatements / data corrections).
5. **Lagged total assets**: atq_{t-1} is the previous quarter's total assets (one row shift within gvkey, sorted by datadate). Invalidated if the date gap between consecutive rows exceeds 150 days (non-consecutive quarter).
6. **Final ratio**: RepurchaseIntensity = quarterly_repurchases / atq_{t-1}. Set to NaN when atq_{t-1} is missing, non-positive, or quarterly_repurchases is NaN.
7. Inf values replaced with NaN after computation.

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| CEO_QA_Uncertainty_pct | CEO Q&A section uncertainty word percentage | (uncertainty word count / total word count) * 100 in CEO Q&A responses | LinguisticEngine | Contemporaneous (t) |
| CEO_Pres_Uncertainty_pct | CEO Presentation section uncertainty word percentage | (uncertainty word count / total word count) * 100 in CEO Presentation | LinguisticEngine | Contemporaneous (t) |
| Manager_QA_Uncertainty_pct | All-manager Q&A section uncertainty word percentage | (uncertainty word count / total word count) * 100 in Manager Q&A responses | LinguisticEngine | Contemporaneous (t) |
| Manager_Pres_Uncertainty_pct | All-manager Presentation section uncertainty word percentage | (uncertainty word count / total word count) * 100 in Manager Presentation | LinguisticEngine | Contemporaneous (t) |

No centering, log-transformation, or z-scoring is applied to the IVs.

### B4. Control Variables

**Base Controls:**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| Size | Firm size | ln(atq), NaN when atq <= 0 | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + dlcq + dlttq) / atq; debt components clipped >= 0, filled 0 if NaN | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets, where avg_assets = (atq_t + atq_{t-1}) / 2 | CompustatEngine: iby, atq |
| BookLev | Book leverage | (dlcq + dlttq) / atq; missing debt treated as 0 | CompustatEngine: dlcq, dlttq, atq |
| CapexAt | Capital expenditure intensity | capxy_annual (Q4) / atq_lag1_annual | CompustatEngine: capxy, atq |
| CashHoldings | Cash holdings ratio | cheq / atq | CompustatEngine: cheq, atq |
| DividendPayer | Dividend payer indicator | 1 if dvy_annual (Q4) > 0, else 0 | CompustatEngine: dvy |
| OCF_Volatility | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of (oancfy / atq_{t-1}) per firm | CompustatEngine: oancfy, atq |
| Lagged_DV | Lagged dependent variable | RepurchaseIntensity_lag (previous fiscal quarter's RepurchaseIntensity); always lags the base DV regardless of whether the spec uses the lead DV | Derived from RepurchaseIntensity |

**Extended Controls (= Base + 4 additional):**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| SalesGrowth | Year-over-year revenue growth | (saley_t - saley_{t-1}) / abs(saley_{t-1}); Q4-only annual; saley with saleq fallback | CompustatEngine: saley, saleq |
| RD_Intensity | R&D intensity | xrdq / atq; missing xrdq treated as 0 | CompustatEngine: xrdq, atq |
| CashFlow | Operating cash flow ratio | oancfy / avg_assets, where avg_assets = (atq_t + atq_{t-1}) / 2; fallback to atq_t | CompustatEngine: oancfy, atq |
| Volatility | Stock return volatility | std(daily_ret) * sqrt(252) * 100, window = [prev_call_date + 5d, call_date - 5d], min 10 trading days | CRSPEngine: RET |

### B5. Fixed Effects

| FE Type | Column Used | Description |
|---------|-------------|-------------|
| Entity (Industry) | ff12_code | Fama-French 12-industry FE via `other_effects` (cols 1, 3, 5, 7, 9, 11) |
| Entity (Firm) | gvkey | Firm FE via `EntityEffects` (cols 2, 4, 6, 8, 10, 12) |
| Time (Calendar Year) | cal_yr | Calendar year FE via `time_effects=True` (cols 1-4, 7-10) |
| Time (Calendar Year-Quarter) | cal_yr_qtr | Calendar year-quarter FE via `time_effects=True` (cols 5-6, 11-12) |

`cal_yr` and `cal_yr_qtr` are derived from the call's `start_date` (calendar date), not from Compustat fiscal year. Computed by `build_cal_yr_qtr_index()` in `panel_utils.py`.

### B6. Standard Errors and Clustering

- **cov_type**: `"clustered"`
- **Clustering dimension**: `cluster_entity=True` (firm-level clustering via gvkey)
- No small-sample corrections beyond the default PanelOLS behavior.

### B7. Hypothesis Test

- **Direction**: Two-tailed
- **P-value computation**: Two-tailed p-values used directly from PanelOLS output (`model.pvalues`). No one-tailed conversion.
- **Significance thresholds**: `***` p < 0.01, `**` p < 0.05, `*` p < 0.10
- The runner stores p-values in `meta[f"{iv}_p_one"]` but the values are actually two-tailed (line 329: `meta[f"{iv}_p_one"] = p_two`). The field name is a legacy misnomer; the values and star computation are correct two-tailed.

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

- **Level**: 1%/99% by fiscal year (fyearq) at CompustatEngine level, using `_winsorize_by_year()` with min 10 observations per year group.
- **Applied to**: Size, TobinsQ, ROA, BookLev, CapexAt, CashHoldings, OCF_Volatility, RD_Intensity, RepurchaseIntensity (all Compustat-derived ratio controls). CashFlow and SalesGrowth are winsorized per-year inside `_compute_biddle_residual` and skipped in the main winsorization loop to avoid double-winsorization.
- **NOT applied to**: Linguistic IVs (bounded [0,100] by construction), DividendPayer (binary), Volatility (CRSP-derived, not winsorized), fqtr (identifier).

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable (DV, IVs, controls, FE identifiers) is NaN.
- Inf/-Inf replaced with NaN before regression (`df.replace([np.inf, -np.inf], np.nan)`), applied in both CompustatEngine (after ratio computation) and runner (before sample filtering).
- RepurchaseIntensity set to NaN when: (a) prstkcy cannot be de-cumulated (Q2-Q4 with missing prior or cross-FY boundary), (b) lagged atq is missing, non-positive, or non-consecutive (gap > 150 days).

### H3. Transformations

- **Size**: natural log of atq (`np.log(atq)`).
- **OCF_Volatility**: rolling standard deviation (5-year window, min 3 years) of annual oancfy/atq_{t-1} ratios.
- **Volatility**: annualized (multiply by sqrt(252) and scale by 100 for percentage).
- No centering, z-scoring, or other transformations on IVs or DV.

## K. MODEL-FAMILY ADDENDUM
------------------------------------------------------------------------

### K1. PanelOLS Specifics

- **Entity effects**:
  - Industry FE (odd cols): Absorbed via `other_effects=df_panel["ff12_code"]` with `entity_effects=False`, `time_effects=True`.
  - Firm FE (even cols): Absorbed via `EntityEffects` in `PanelOLS.from_formula()` with `TimeEffects`.
- **Time effects**: Absorbed via `time_effects=True` (both API and formula paths).
  - `cal_yr` used as panel time index for Calendar Year FE specs.
  - `cal_yr_qtr` used as panel time index for Year-Quarter FE specs.
- **drop_absorbed**: `True` for all specifications.
- **check_rank**: `False` for industry FE specifications (API path); default for firm FE specifications (formula path).
- **Singleton handling**: Default PanelOLS behavior (singletons dropped via `drop_absorbed=True`).
- **R-squared reporting**: Overall R-squared (`model.rsquared`) plus manually computed Adjusted R-squared: `1 - (1 - R2) * (nobs - 1) / df_resid`.

## L. KNOWN ISSUES AND NOTES
------------------------------------------------------------------------

1. **~77% zero mass point**: The runner docstring (line 32) and LaTeX notes (line 483) document that approximately 77% of firm-quarters have RepurchaseIntensity = 0, because most firms do not repurchase shares every quarter. OLS with a continuous DV is used despite this high zero-mass; a Tobit or hurdle model might be more appropriate but is not implemented.

2. **prstkcy includes preferred stock**: Compustat's prstkcy captures both common and preferred stock repurchases. This is standard in the empirical literature but means the measure is not purely common-stock buybacks.

3. **Legacy field name `_p_one`**: The runner stores two-tailed p-values in the metadata key `f"{iv}_p_one"` (line 329: `meta[f"{iv}_p_one"] = p_two`). The variable name is a legacy misnomer carried from one-tailed suites. The star computation and LaTeX table output are correctly two-tailed.

4. **Lead/lag consecutive-quarter validation**: The panel builder validates that leads and lags are truly consecutive fiscal quarters (Q1->Q2->Q3->Q4->Q1_next_year). Non-consecutive quarters (e.g., missing intermediate quarter) produce NaN leads/lags rather than incorrect shifts. This is implemented via `fiscal_qtr_id` arithmetic (lines 260-268 in panel builder).

5. **Lagged_DV always lags base DV**: For lead DV specifications (cols 7-12), Lagged_DV is still `RepurchaseIntensity_lag` (the lag of the contemporaneous DV), not the lag of the lead DV. This is by design (runner line 210: `base_dv = dv.replace("_lead_qtr", "").replace("_lead", "")`).

6. **De-cumulation Q1 NaN handling**: For Q1, missing prstkcy is filled with 0 (line 1053: `comp["prstkcy"].fillna(0)`). This means firms with truly missing Q1 prstkcy are treated as having zero repurchases rather than excluded. This is a conservative assumption.
