## B. MODEL SPECIFICATION

### B1. Regression Equation

For each model column, the estimator fits:

```
DV_{i,t} = b1 * Manager_QA_Unc_c + b2 * z(log(MOD)) + b3 * (Manager_QA_Unc_c x z(log(MOD)))
          + b4 * Lagged_DV + Controls + Industry_FE(ff12) + Time_FE + epsilon_{i,t}
```

Where:
- `MOD` = TNIC3TSIMM for all 4 columns
- `Time_FE` = Calendar Year (cols 1-2) or Calendar Year-Quarter (cols 3-4)
- `b3` is the coefficient of interest (moderation effect)
- `Manager_QA_Unc_c` is the mean-centered IV (centered on Main sample mean)

Source: `run_h13_1_competition.py`, lines 12-13 (docstring), lines 398, 410-418 (estimation).

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|----------------------|-------------|---------|---------------|--------|
| CapexAt | Capital expenditure scaled by lagged total assets | capxy_annual (Q4 full-year) / atq_annual_lag1 | CompustatEngine: capxy, atq, fqtr, fyearq | Contemporaneous (t) |
| CapexAt_lead | Capital expenditure intensity in fiscal year t+1 | Shift of CapexAt by -1 within gvkey on fiscal year, requiring consecutive fiscal years | CompustatEngine via panel builder lead construction | Lead (t+1) |

Source: `_compustat_engine.py`, lines 994-999 (CapexAt); `build_h13_capex_panel.py`, lines 215-337 (CapexAt_lead).

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|----------------------|-------------|---------|---------------|--------|
| Manager_QA_Uncertainty_pct | Raw Manager Q&A Uncertainty percentage | Word-level uncertainty percentage from Q&A section of earnings calls | LinguisticEngine: Stage 2 textual analysis outputs | Contemporaneous |
| Manager_QA_Unc_c | Mean-centered Manager Q&A Uncertainty | Manager_QA_Uncertainty_pct - mean(Manager_QA_Uncertainty_pct) on Main sample | Computed in runner at load time | Contemporaneous |
| z_log_tnic3tsimm | Standardized log TNIC3 Total Similarity (moderator) | z-score of log(tnic3tsimm), computed on Main sample: (log(tnic3tsimm) - mu) / sd | TNIC3HHIdata.txt: tnic3tsimm | Fiscal year (firm-year) |
| MgrQAUnc_x_zlogTSIMM | Interaction: centered IV x z(log(TSIMM)) | Manager_QA_Unc_c * z_log_tnic3tsimm | Computed in runner prepare_regression_data() | Contemporaneous |

Centering and standardization details (from `run_h13_1_competition.py`, lines 249-298):
- IV centering: `Manager_QA_Unc_c = Manager_QA_Uncertainty_pct - mean(Main sample)`
- Moderator standardization: `z = (log(raw) - mu_Main) / sd_Main`
- Interaction: product of centered IV and z-scored moderator

- `cov_type="clustered"` with `cluster_entity=True`

### B7. Hypothesis Test

- **Direction:** Two-tailed for ALL coefficients (IV, moderator, interaction, controls)
- **P-value computation:** Two-tailed p-values used directly from PanelOLS output; no one-tailed conversion
- **Significance thresholds:** `*** p<0.01`, `** p<0.05`, `* p<0.10`
- **Per-variable tail specification:** All variables are two-tailed (confirmed by `key_tails: ["two", "two", "two"]` in generate_all_tables.py, covering Manager_QA_Unc_c, z_log_tnic3tsimm, and MgrQAUnc_x_zlogTSIMM)

Source: `run_h13_1_competition.py`, lines 426-443 (p-value extraction uses `model.pvalues` directly); lines 474-484 (`_sig_stars` function uses two-tailed thresholds). The runner docstring (line 42) states: "Hypothesis: All two-tailed (matching parent H13)."

## F. DATA PIPELINE

### F1. Dependency Chain

1. **Raw inputs:**
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` (112,968 calls)

   - CompustatEngine (singleton): loads Compustat quarterly, computes all financial controls + CapexAt, winsorizes by fiscal year

   - CRSPEngine (singleton): loads CRSP daily returns, computes inter-call volatility

3. **Panel builder** (`build_h13_capex_panel.py`):
   - Loads manifest as base (one row per call)

   - Assigns industry sample (Main/Finance/Utility from ff12_code)

4. **Runner loading** (`run_h13_1_competition.py`):
   - Loads H13 panel parquet (selects specific columns)
   - Builds cal_yr_qtr index from start_date
   - Merges TNIC3HHIdata on (gvkey_int, fyearq_int) -- left join (loads tnic3tsimm only)
   - Log-transforms + z-scores TSIMM moderator on Main sample
   - Mean-centers IV on Main sample

5. **Sample filtering** (per spec):
   - Exclude Finance (FF12=8) and Utility (FF12=11)
   - Replace inf/-inf with NaN
   - Create interaction term (centered IV x z-scored moderator)
   - Drop rows with NaN in DV
   - Complete-case deletion (all required variables non-null)

6. **Regression estimation:**
   - PanelOLS: 4 specs (2 DVs x 1 moderator x 2 time FE)

## H. OUTLIER AND MISSING DATA TREATMENT

### H1. Winsorization

**Compustat financial variables (CompustatEngine level):**
- Level: 1%/99% by fiscal year (`_winsorize_by_year`, min 10 obs per year group)
- Applied to: Size, TobinsQ, ROA, BookLev, CashHoldings, CapexAt, OCF_Volatility, RD_Intensity
- NOT applied to: DividendPayer (binary), CashFlow/SalesGrowth (winsorized separately inside Biddle engine to avoid double-winsorization)

**Linguistic variables (LinguisticEngine level):**
- Level: 0%/99% upper-only by calendar year
- Applied to: Manager_QA_Uncertainty_pct (and all _pct columns)
- Rationale: Linguistic percentages are bounded [0, ~2%]; only upper tail needs trimming

**TNIC moderators:** Not winsorized (log-transformed and z-scored instead)

**Volatility (CRSPEngine level):** Not winsorized at engine level

Source: `_compustat_engine.py`, lines 1115-1136 (Compustat winsorization); `_linguistic_engine.py`, lines 254-258 (linguistic winsorization).

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (`run_h13_1_competition.py`, lines 353-357)
- Inf/-Inf replaced with NaN before regression (`run_h13_1_competition.py`, line 343)
- TNIC merge is left join; unmatched calls get NaN moderator (dropped at complete-case step)
- CapexAt_lead/lag set to NaN for non-consecutive fiscal years or last/first fiscal year per firm

### H3. Transformations

| Variable | Transformation | Details |
|----------|---------------|---------|
| Manager_QA_Uncertainty_pct | Mean-centering | Subtract Main sample mean (iv_mu) |
| tnic3tsimm | Log + z-score | log(raw), then (log - mu_Main) / sd_Main |
| Size | Log | ln(atq) applied at CompustatEngine level |

## L. KNOWN ISSUES AND NOTES

1. **Report docstring FE label inconsistency:** The report file (`report_step4_H13_1.md`, line 8) labels cols 1-4 as "Industry(FF12) + FiscalYear" and uses "FY" shorthand in the table. However, the code uses `cal_yr` (calendar year from start_date, line 335) as the time index, not fiscal year. The calendar year designation in the runner code (line 44: `Panel index: ["gvkey", "cal_yr"]`) and `build_cal_yr_qtr_index()` confirm these are calendar-year FE. **Code is truth: Calendar Year FE, not Fiscal Year FE.**

2. **TNIC3TSIMM is a firm-year measure, repeated across calls:** TNIC3TSIMM is an annual firm-level measure merged to calls via (gvkey, fyearq_int). Multiple calls from the same firm in the same fiscal year share identical moderator values. This does not violate the specification but means within-firm-year variation in the interaction term comes entirely from the centered IV.

3. **Lagged_DV always uses CapexAt_lag:** For both CapexAt and CapexAt_lead DVs, `Lagged_DV = CapexAt_lag` (the previous fiscal year's CapexAt). This is set in `prepare_regression_data()` line 326-329 where `base_dv = dv.replace("_lead_qtr", "").replace("_lead", "")` extracts "CapexAt", and `lag_col = "CapexAt_lag"`.

4. **H13.1 redesign history:** This suite replaces an earlier H13.1 design that had uncentered interactions, HHI-only moderator, 16 models with 4 separate IVs, and only 1/16 significant results that failed Bonferroni correction. A subsequent transitional design added TSIMM as primary moderator alongside HHI (8 columns). The current design uses only TSIMM (4 columns) as the primary moderator. See runner docstring.

5. **No CapexIntensity control exclusion note:** CapexIntensityBuilder provides the CapexAt DV. The DV itself (CapexAt) does not appear in the CONTROLS list — Lagged_DV (CapexAt_lag) serves as the lagged-DV control. No bad-control issue exists because the lagged DV is temporally prior.

6. **Panel builder also loads 4 IVs (CEO_QA, CEO_Pres, Manager_QA, Manager_Pres):** The H13 shared panel builder loads all 4 uncertainty measures, but the H13.1 runner only uses Manager_QA_Uncertainty_pct. The other three IVs are available in the panel but unused by this suite.

7. **Provenance document corrected from 8-column to 4-column design (2026-04-01 audit):** The previous version of this document described a transitional 8-column design (TSIMM + HHI as dual moderators). The runner was redesigned to 4 columns with TSIMM as the sole moderator (as of 2026-03-31). All HHI references (tnic3hhi, z_log_tnic3hhi, MgrQAUnc_x_zlogHHI) have been removed from this document to match the current codebase.
