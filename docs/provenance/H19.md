Hypothesis:      Does speech uncertainty during earnings calls predict whether

## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

```
ExternalFunding_{i,t} = b1*CEO_QA_Uncertainty_pct + b2*CEO_Pres_Uncertainty_pct
                      + b3*Manager_QA_Uncertainty_pct + b4*Manager_Pres_Uncertainty_pct
                      + Controls + alpha_j + gamma_t + epsilon_{i,t}
```

Where:
- `alpha_j` = Industry (FF12) FE (odd columns) or Firm FE (even columns)
- `gamma_t` = Calendar Year FE (cols 1-4, 7-10) or Calendar Year-Quarter FE (cols 5-6, 11-12)
- `i` = individual earnings call, `t` = calendar year or calendar year-quarter
- LPM: binary DV estimated with OLS (PanelOLS), not logit/probit

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| ExternalFunding | Binary: firm used external financing in current fiscal year | 1 if debt or equity issuance >5% of lagged total assets; 0 if neither threshold met | CompustatEngine: dlcq, dlttq, sstky, prstkcy, atq | Contemporaneous (fiscal year T) |
| ExternalFunding_lead | Binary: firm used external financing in next fiscal year | Same classification, shifted forward by fiscal year +1 | CompustatEngine + fiscal year shift | Lead (fiscal year T+1) |

**Construction detail** (from `_compustat_engine.py`, lines 1094-1178):

1. **Debt issuance** (balance sheet change): Total debt at Q4 = dlcq + dlttq (missing treated as 0; both-NaN preserved as NaN). Annual debt change = Q4 total debt(T) - Q4 total debt(T-1). Ratio = change / lagged total assets (atq at Q4 of T-1).

2. **Equity issuance** (cash flow statement): Net equity issuance = sstky(Q4) - prstkcy(Q4). Both are YTD cumulative fields; Q4 value gives full-year total. Ratio = net equity / lagged total assets.

3. **Classification** (Leary & Roberts 2010, Table 3, p.341):
   - External = 1 if debt ratio > 5% OR equity ratio > 5%
   - Internal = 0 if neither ratio exceeds 5%
   - Dual issuers (both > 5%) classified as equity per L&R convention
   - Threshold constant: `_LR_THRESHOLD = 0.05` (engine line 1159)

4. **Lead/lag** (from `build_h19_h20_financing_panel.py`, `create_financing_dvs`, lines 177-261):
   - Builds firm-year lookup of ExternalFunding from first call per (gvkey, fyearq)
   - Lead: shifts fyearq-1 so next year's classification joins to current year
   - Lag: shifts fyearq+1 so previous year's classification joins to current year
   - Both are left-merged onto call-level panel on (gvkey, fyearq_int)

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| CEO_QA_Uncertainty_pct | CEO Q&A uncertainty word percentage | (Uncertainty word count / total word count) * 100, CEO Q&A section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| CEO_Pres_Uncertainty_pct | CEO presentation uncertainty word percentage | (Uncertainty word count / total word count) * 100, CEO presentation section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| Manager_QA_Uncertainty_pct | All-manager Q&A uncertainty word percentage | (Uncertainty word count / total word count) * 100, all managers Q&A section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| Manager_Pres_Uncertainty_pct | All-manager presentation uncertainty word percentage | (Uncertainty word count / total word count) * 100, all managers presentation section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |

All four IVs are bounded [0, ~2.5] by construction (percentage of Loughran-McDonald uncertainty words). Winsorized per-year 0%/99% (upper-only) at LinguisticEngine level.

### B4. Control Variables

**Base Controls** (cols 1-2, 7-8):

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| Size | Firm size | ln(atq), atq > 0 only | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + debt_book) / atq | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets | CompustatEngine: iby, atq |
| BookLev | Book leverage | (dlcq + dlttq) / atq, missing debt = 0 | CompustatEngine: dlcq, dlttq, atq |
| CapexAt | Capital expenditure intensity | capxy_annual (Q4) / atq_lag | CompustatEngine: capxy, atq |
| CashHoldings | Cash ratio | cheq / atq | CompustatEngine: cheq, atq |
| DividendPayer | Dividend payer indicator | 1 if dvy_annual (Q4) > 0, else 0 | CompustatEngine: dvy |
| OCF_Volatility | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of oancfy / atq_{t-1} | CompustatEngine: oancfy, atq |
| Lagged_DV | Lagged ExternalFunding | ExternalFunding_lag = previous fiscal year's classification | CompustatEngine + fiscal year shift |

**Extended Controls** (cols 3-6, 9-12): Base Controls plus:

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| SalesGrowth | Revenue growth | (saley_t - saley_{t-1}) / abs(saley_{t-1}), Q4 annual | CompustatEngine: saley, saleq (fallback) |
| RD_Intensity | R&D intensity | xrdq / atq, missing xrdq = 0 | CompustatEngine: xrdq, atq |
| CashFlow | Operating cash flow scaled | oancfy / avg_assets, avg = (atq_t + atq_{t-1})/2 | CompustatEngine: oancfy, atq |
| Volatility | Stock return volatility | std(daily_ret) * sqrt(252) * 100 over inter-call window | CRSPEngine: daily returns |

**Lagged_DV detail**: In `prepare_regression_data()` (runner line 211), `Lagged_DV` is assigned from `ExternalFunding_lag`, which is the previous fiscal year's ExternalFunding binary classification. This is a single unified row across all specifications.

### B5. Fixed Effects

| FE Type | Column Used | Description | Cols |
|---|---|---|---|
| Industry | ff12_code | Fama-French 12-industry via `other_effects` | 1, 3, 5, 7, 9, 11 |
| Firm | gvkey | Entity FE via `EntityEffects` | 2, 4, 6, 8, 10, 12 |
| Calendar Year | cal_yr | start_date.dt.year via `time_effects=True` | 1-4, 7-10 |
| Calendar Year-Quarter | cal_yr_qtr | year*10+quarter via `time_effects=True` | 5-6, 11-12 |

Calendar year and year-quarter are derived from the call's `start_date` (not fiscal year). Constructed in `build_cal_yr_qtr_index()` in `panel_utils.py` (lines 195-218).

### B6. Standard Errors and Clustering

- `cov_type="clustered"`, `cluster_entity=True` (runner lines 290, 295)
- Clustering dimension: entity (gvkey) -- firm-clustered standard errors
- No small-sample correction beyond what PanelOLS applies by default

### B7. Hypothesis Test

- Direction: **one-tailed (beta < 0)** -- higher uncertainty reduces external funding probability
- P-value computation (runner lines 322-324):
  ```python
  if beta < 0:
      p_one = p_two / 2
  else:
      p_one = 1 - p_two / 2
  ```
- Significance thresholds: `***` p < 0.01, `**` p < 0.05, `*` p < 0.10 (runner lines 336-345)
- All four IVs share the same one-tailed direction
- Verified manually: Col 1, Mgr QA Uncertainty: beta=-0.0156, t=-1.3098, p_two=0.1903, p_one=0.1903/2=0.0952. Reported=0.0951. **MATCHES.**

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

**Compustat controls**: 1%/99% per fiscal year (fyearq), applied at CompustatEngine level (`_compute_and_winsorize`, `_compustat_engine.py` lines 1225-1232).
- Applied to: Size, BookLev, TobinsQ, ROA, CapexAt, CashHoldings, RD_Intensity, OCF_Volatility, CashFlow, SalesGrowth
- NOT applied to: DividendPayer (binary), ExternalFunding (binary, in skip_winsorize set at line 1222), DebtChoice (binary, in skip_winsorize set at line 1223), Volatility (CRSP, not in Compustat engine)

**Linguistic IVs**: 0%/99% per year (upper-only), applied at LinguisticEngine level.
- Applied to: all four _pct IV columns
- Rationale: lower bound is 0% by construction; only upper tail clipped

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (runner lines 230-231)
- Inf/-Inf replaced with NaN before regression (runner line 222)
- Missing R&D (xrdq) treated as zero per standard convention (CompustatEngine line 972)
- Missing debt (dlcq, dlttq) treated as zero for BookLev (CompustatEngine line 948); but both-NaN = NaN for classification (engine line 1110-1112)
- ExternalFunding NaN rate: 652/88,205 (0.74%) in main sample -- low, due to missing Compustat inputs for classification
- ExternalFunding_lead NaN rate: 6,605/88,205 (7.49%) -- higher due to panel boundary effects
- ExternalFunding_lag NaN rate: 6,106/88,205 (6.92%) -- same boundary effects

### H3. Transformations

- Size: natural log of total assets (ln(atq))
- Volatility: annualized (multiply by sqrt(252)) and expressed as percentage (* 100)
- No centering, z-scoring, or other transformations applied to IVs or other controls

This suite uses PanelOLS as a Linear Probability Model (LPM) for a binary DV. The binary DV (ExternalFunding in {0, 1}) is estimated with linear regression rather than logit/probit.

**Methodological justification** (runner docstring lines 28-33):
- Timoneda (2021, Social Science Research): Monte Carlo evidence shows LPM-FE outperforms logit at base rates <5%.
- At low treatment rates, heteroscedasticity is negligible (Var = p(1-p)), linearity approximation excellent, no incidental parameters problem, no sample loss.

**AUDIT NOTE**: The Timoneda (2021) justification is **misapplied** to this suite. The ExternalFunding base rate is 26.6% -- far above the <5% threshold where Timoneda's Monte Carlo evidence supports LPM over logit. At 26.6% base rate, Var(p) = 0.266 * 0.734 = 0.195, and heteroscedasticity is NOT negligible. The LPM may still be acceptable on other grounds (simplicity, FE absorption, direct marginal effects), but the specific Timoneda citation does not support its use here. See Section L (Known Issues), Issue #1.

**Entity effects**:
- Industry FE (odd cols): absorbed via `other_effects=df_panel["ff12_code"]`, `entity_effects=False`, `time_effects=True` (runner lines 281-289)
- Firm FE (even cols): absorbed via `EntityEffects` in PanelOLS formula, `TimeEffects` (runner lines 293-294)
- `drop_absorbed=True` in all specifications (runner lines 287, 294)

**Time effects**: absorbed via `time_effects=True` (industry specs) or `TimeEffects` in formula (firm specs). Panel index time dimension is `cal_yr` (cols 1-4, 7-10) or `cal_yr_qtr` (cols 5-6, 11-12), determined at runner line 260.

**Singleton handling**: PanelOLS default behavior. `check_rank=False` set for industry FE specs (runner line 288).

**R-squared reporting**: Both R-squared (overall) and Adjusted R-squared are reported. Adj R-squared is computed manually as `1 - (1 - R2) * (nobs - 1) / df_resid` (runner lines 301, 311). R-squared ranges from 0.032 to 0.102.

### Issue #1: Timoneda (2021) LPM Justification is Misapplied [MAJOR]

**Severity**: Major (methodological justification error)

The runner's docstring and LaTeX table note both cite Timoneda (2021) to justify using LPM over logit, specifically claiming "LPM-FE outperforms logit at base rates <5%." However, the ExternalFunding base rate is **26.6%** (23,289 external / 87,553 non-null in main sample). This is over 5x the <5% threshold where Timoneda's Monte Carlo evidence applies.

At 26.6% base rate:
- Heteroscedasticity is substantial: Var(p) = p(1-p) = 0.195
- The linearity approximation may not be excellent across the full covariate space
- Logit is a viable and potentially preferable alternative
- The incidental parameters problem with firm FE (which is a genuine LPM advantage over logit) is less severe at high base rates because fewer firms will have perfectly predicted outcomes

**Recommendation**: Either (a) remove the Timoneda citation and replace with a more appropriate justification for LPM at moderate base rates (e.g., Angrist & Pischke 2009, "Mostly Harmless Econometrics," who argue LPM is generally fine when marginal effects at means are the estimand), or (b) add logit robustness checks.

### Issue #2: BookLev is a Bad Control [MODERATE]

**Severity**: Moderate (identification concern)

BookLev = (dlcq + dlttq) / atq. The DV ExternalFunding's debt channel uses delta(dlcq + dlttq) / lagged_atq > 5%. BookLev shares the dlcq+dlttq numerator concept with the DV's debt issuance component. A firm that issues debt (ExternalFunding=1 via debt channel) mechanically has higher BookLev in the same period.

Empirically confirmed: Corr(ExternalFunding, BookLev) = 0.168 in main sample.

This violates the "bad control" exclusion rule (see `feedback_bad_control_exclusion.md`): controls sharing the DV's numerator concept should be excluded. Note that the companion H20 suite (DebtChoice) correctly EXCLUDES BookLev from its control set (H20 `BASE_CONTROLS` omits BookLev -- confirmed in `run_h20_debt_choice.py`).

**Recommendation**: Remove BookLev from H19 controls to be consistent with H20 and the bad-control exclusion principle. The bias direction is ambiguous -- BookLev may absorb variation that should be attributed to the IVs, attenuating estimated effects.

### Issue #3: Look-Ahead Bias in Contemporaneous DV [MODERATE]

**Severity**: Moderate (temporal alignment concern)

ExternalFunding is an ANNUAL classification computed from Q4 (fiscal year-end) data -- specifically Q4 values of dlcq, dlttq, sstky, and prstkcy. However, this classification is assigned to ALL calls within the same fiscal year, including Q1, Q2, and Q3 calls that occur BEFORE the fiscal year's financing activity is complete.

For a call in Q1 of fiscal year T, the DV ExternalFunding uses data from Q4 of fiscal year T, which will not be available until 6-9 months after the call. This means the "contemporaneous" DV actually incorporates future information relative to the call date.

This is less problematic than it appears for two reasons: (1) the hypothesis direction (beta < 0) tests whether uncertain speech REDUCES future external funding, so the temporal ordering (speech before funding) is directionally correct even within the fiscal year; (2) the lead DV (ExternalFunding_lead, fiscal year T+1) provides a cleaner test with full temporal separation. However, the issue should be disclosed.

**Recommendation**: Note this in the thesis discussion. The lead DV specifications (cols 7-12) provide the more defensible temporal identification.

### Issue #4: Almost Complete Null Result [INFORMATIONAL]

**Severity**: Informational (empirical finding, not a bug)

Across 48 IV-column combinations (4 IVs x 12 cols):
- **0 out of 48** are significant at p < 0.05 (one-tailed, beta < 0)
- **6 out of 48** are significant at p < 0.10 (one-tailed, beta < 0)
  - Manager_QA_Uncertainty_pct: cols 1, 3, 5 (contemporaneous, industry FE only)
  - Manager_Pres_Uncertainty_pct: cols 8, 10, 12 (lead, firm FE only)
- By chance alone at alpha=0.10, we would expect ~4.8 out of 48 significant results
- CEO_QA_Uncertainty_pct has the WRONG sign (positive) in ALL 12 columns
- Manager_Pres_Uncertainty_pct has the wrong sign (positive) in 9 out of 12 columns

The weak significance of Manager_QA in contemporaneous industry FE specs disappears entirely under firm FE. The marginal significance of Manager_Pres in lead firm FE specs is sensitive to specification. This is consistent with a null effect.

### Issue #5: Extremely Low Adj R-squared in Firm FE Lead Models [INFORMATIONAL]

**Severity**: Informational

Firm FE models with lead DV (cols 8, 10, 12) have Adj R-squared of 0.003-0.004, essentially zero explanatory power after accounting for the degrees of freedom consumed by firm fixed effects. This suggests that firm FE absorb nearly all the variation that the controls explain, and the model adds negligible predictive power beyond firm identity. The overall R-squared of 0.034 is entirely attributable to firm effects.

### Issue #6: LaTeX Table Omits Control Coefficients [MINOR]

**Severity**: Minor (formatting concern)

The LaTeX table (`_save_latex_table`) shows only the four IV coefficient rows. Per the project convention documented in `feedback_table_format.md`, the standard academic format requires "all controls shown." The 9 base controls and 4 extended controls are not displayed. Only "Controls: Base/Extended" and "Lagged DV: Yes" indicator rows are shown.

**Recommendation**: Add control coefficient rows or at minimum note that full results are available in the individual regression output files.

### Issue #7: Duplicate (gvkey, time) Panel Index [INFORMATIONAL]

**Severity**: Informational (not a blocker per `feedback_duplicate_panel_index.md`)

The panel index (gvkey, cal_yr) has 87,445 duplicates (expected: call-level panel with multiple calls per firm-year). The (gvkey, cal_yr_qtr) index has 8,952 duplicates (multiple calls in the same calendar quarter). PanelOLS handles duplicates by treating them as repeated observations within entity-time cells. This is standard for call-level panels.

### Issue #8: ExternalFunding is Annual but Panel is Call-Level [INFORMATIONAL]

**Severity**: Informational (design choice)

The DV is a firm-year level variable (same value for all calls in a fiscal year, verified: 0 firm-years with inconsistent ExternalFunding). This means within-firm-year variation in IVs does not contribute to identification in the contemporaneous DV specs. Identification comes from ACROSS firm-year variation in call-level uncertainty, which is then matched to an annual outcome. The call-level panel with annual DV inflates the apparent sample size (55,639 calls but only ~8,300 unique firm-years) and may affect standard error inference despite clustering.

### Issue #9: Fiscal Year vs Calendar Year Mismatch [INFORMATIONAL]

**Severity**: Informational

24.35% of calls have calendar year != fiscal year (21,464 mismatches in main sample). The DV is defined by fiscal year (ExternalFunding for fiscal year T), but time FE use calendar year from start_date. This means firms with non-December fiscal year-ends have their DV defined in fiscal-year space but FE absorption in calendar-year space. This is a standard tension in call-level panels and is handled consistently across all suites.
