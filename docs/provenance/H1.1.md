## B. MODEL SPECIFICATION

### B1. Regression Equation

$$
\text{CashHoldings}_{i,t} = \beta_1 \cdot \text{MgrQAUnc\_c}_{i,t}
  + \beta_2 \cdot z(\log(\text{TSIMM}))_{i,t}
  + \beta_3 \cdot (\text{MgrQAUnc\_c} \times z(\log(\text{TSIMM})))_{i,t}
  + \gamma \cdot \mathbf{Controls}_{i,t}
  + \alpha_{\text{ff12}} + \delta_t + \varepsilon_{i,t}
$$

Where:
- $\alpha_{\text{ff12}}$ = Fama-French 12-industry fixed effects (via `other_effects`)
- $\delta_t$ = Calendar Year FE (Col 1) or Calendar Year-Quarter FE (Col 2) (via `time_effects=True`)
- $\beta_1$ = main IV effect at the sample mean of TSIMM (because the IV is mean-centered)
- $\beta_3$ = coefficient of interest -- does product similarity moderate the uncertainty-cash relationship?

Source: `run_h1_1_cash_tsimm.py`, lines 86-89 (MODEL_SPECS), lines 348-371 (PanelOLS instantiation).

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| CashHoldings | Cash and short-term investments / total assets | cheq / atq | CompustatEngine: cheq, atq | Contemporaneous (t) |

Source: `_compustat_engine.py`, line 981: `comp["CashHoldings"] = comp["cheq"] / comp["atq"]`.

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| Manager_QA_Unc_c | Manager Q&A uncertainty, mean-centered on Main sample | Manager_QA_Uncertainty_pct - mean(Main sample) | LinguisticEngine: Stage 2 outputs | Contemporaneous (t) |
| z_log_tnic3tsimm | TNIC3 total similarity index, log-transformed and z-scored on Main sample | (log(tnic3tsimm) - mu) / sd, where mu and sd computed on Main sample | TNIC3HHIdata.txt: tnic3tsimm column | Firm-year (matched on gvkey + fyearq_int) |
| MgrQAUnc_x_zlogTSIMM | Interaction of centered IV and z-scored moderator | Manager_QA_Unc_c * z_log_tnic3tsimm | Computed in runner at regression time | Contemporaneous (t) |

**IV centering logic** (lines 206-254 of runner):
- `Manager_QA_Unc_c` = `Manager_QA_Uncertainty_pct` minus its mean on the Main sample (ff12 not in {8, 11}), computed after FF12 filter but before complete-case deletion.
- Purpose: reduces multicollinearity between moderator and interaction from Corr ~0.93 (uncentered) to Corr ~0.12 (centered).

**Moderator transformation** (lines 224-237 of runner):
- log-transform applied to raw tnic3tsimm across all rows: `log_tnic3tsimm = np.log(tnic3tsimm)`.
- z-score computed using Main-sample moments only: `(log_tnic3tsimm - mu) / sd`.
- Both mu and sd are derived from `panel.loc[main_mask, MODERATOR_RAW].dropna()` then `np.log(...)`.

**Interaction construction** (line 300 of runner):
- `df[INTERACTION] = df[IV_CENTERED] * df[MODERATOR]` -- product of centered IV and z-scored moderator.
- Created inside `prepare_regression_data()`, per-spec (not pre-computed on full panel).

## F. DATA PIPELINE

### F1. Dependency Chain

1. **Raw inputs:**
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` (call manifest)
   - `inputs/comp_na_daily_all/comp_na_daily_all.parquet` (Compustat quarterly)
   - `inputs/CRSP_DSF/CRSP_DSF_{year}_Q{q}.parquet` (CRSP daily returns)
   - `outputs/2_Textual_Analysis/2.2_Variables/latest/linguistic_variables_{year}.parquet` (linguistic variables)
   - `inputs/TNIC3HHIdata/TNIC3HHIdata.txt` (Hoberg-Phillips TNIC data)

2. **Engine loading:**
   - CompustatEngine (singleton): loads Compustat quarterly, computes all financial controls via `_compute_and_winsorize()`, applies 1%/99% winsorization by fiscal year.
   - CRSPEngine (singleton): loads CRSP daily returns, computes Volatility per call.
   - LinguisticEngine (singleton): loads Stage 2 linguistic variables, applies 0%/99% upper-only winsorization by calendar year.

3. **Panel builder** (`build_h1_cash_holdings_panel.py`):
   - Loads manifest as base (file_name-unique rows).
   - Merges all builder outputs on `file_name` (left join, zero-row-delta enforced).
   - Attaches `fyearq` via `merge_asof` (call start_date to nearest Compustat datadate).
   - Creates `CashHoldings_lead` (shift -1 within gvkey by fyearq, consecutive-year validated).
   - Creates `CashHoldings_lag` (shift +1 within gvkey by fyearq, consecutive-year validated).
   - Assigns industry sample (Main/Finance/Utility via ff12_code).
   - Outputs: `h1_cash_holdings_panel.parquet`.

4. **Runner loading** (`run_h1_1_cash_tsimm.py`):
   - Loads H1 panel (specific columns only: start_date, gvkey, year, fyearq_int, ff12_code, CashHoldings, CashHoldings_lag, IV, and all controls except Lagged_DV).
   - Builds `cal_yr_qtr` index via `build_cal_yr_qtr_index()`.
   - Merges TNIC3 data: joins `tnic3tsimm` from TNIC3HHIdata.txt on (_gvkey_int, fyearq_int) = (gvkey, year) via left join.
   - Transforms moderator and centers IV on Main sample.
   - Filters to Main sample (ff12 not in {8, 11}).

5. **Sample filtering** (per spec, inside `prepare_regression_data()`):
   - Creates `Lagged_DV` from `CashHoldings_lag`.
   - Creates interaction term: `MgrQAUnc_x_zlogTSIMM = Manager_QA_Unc_c * z_log_tnic3tsimm`.
   - Replaces inf/-inf with NaN.
   - Drops rows where DV is NaN.
   - Complete-case deletion on all required columns.
   - Drops firms with < 5 calls.

6. **Regression estimation:**
   - PanelOLS with `entity_effects=False`, `time_effects=True`, `other_effects=ff12_code`, `drop_absorbed=True`.
   - Fit with `cov_type="clustered", cluster_entity=True`.
   - 2 specs run sequentially.

7. **Table generation:**
   - Runner writes its own LaTeX table (`h1_1_cash_tsimm_table.tex`).
   - Also has entry in `outputs/generate_all_tables.py` for standardized table generation.

## H. OUTLIER AND MISSING DATA TREATMENT

### H1. Winsorization

**CompustatEngine level (1%/99% by fiscal year):**
Applied to: CashHoldings, BookLev, Size, TobinsQ, ROA, CapexAt, OCF_Volatility, RD_Intensity, CurrentRatio.
Skipped: DividendPayer (binary), CashFlow and SalesGrowth (already winsorized per-year inside Biddle residual computation).
Method: `_winsorize_by_year()` with min_obs=10 per year group.

Source: `_compustat_engine.py`, lines 1115-1136.

**LinguisticEngine level (0%/99% upper-only by calendar year):**
Applied to: Manager_QA_Uncertainty_pct (and all other `_pct` columns).
Method: `winsorize_by_year()` with lower=0.0, upper=0.99, min_obs=10.

Source: `_linguistic_engine.py`, lines 235-257.

**Not winsorized:**
- Volatility (bounded by construction -- annualized std of daily returns)
- tnic3tsimm, z_log_tnic3tsimm (raw moderator not winsorized; z-scoring is a standardization, not truncation)
- MgrQAUnc_x_zlogTSIMM (interaction, not independently winsorized)

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (runner lines 308-310).

## L. KNOWN ISSUES AND NOTES

1. **Shared panel builder:** H1.1 loads the H1 panel (`h1_cash_holdings_panel.parquet`) built by `build_h1_cash_holdings_panel.py`. The TNIC3 data is merged at runner load time (not in the panel builder), making the runner responsible for the moderator data pipeline. This means rebuilding the H1 panel does not incorporate TNIC data -- only the runner merge does.

2. **CashHoldings_lead not used in H1.1:** The H1 panel builder creates both `CashHoldings_lead` and `CashHoldings_lag`, but H1.1 only uses `CashHoldings_lag` (as Lagged_DV). The lead variable is used by the parent H1 suite for its lead-DV specifications. The runner explicitly loads only `CashHoldings_lag` in its column selection (line 156).

3. **CurrentRatio in panel but not in regression:** The panel builder includes `CurrentRatioBuilder`, but the H1.1 runner does not include `CurrentRatio` in CONTROLS (line 72-77). It is built in the panel for other suites sharing the H1 panel.

4. **TNIC merge key type conversion:** The runner converts `gvkey` (string) to `_gvkey_int` (numeric) for merging with TNIC data, which stores gvkey as integer. A pandas `to_numeric(errors="coerce")` is used, so any non-numeric gvkey values silently become NaN and fail to match (runner lines 186-197).

5. **Moderator is firm-year, not call-level:** TNIC3TSIMM is a firm-year variable. All calls within the same (gvkey, fyearq) receive the same tnic3tsimm value. This means within-firm-year variation in the interaction comes entirely from the call-level IV (Manager_QA_Uncertainty_pct). The LaTeX table notes explicitly acknowledge this (runner line 571).

6. **TobinsQ formula discrepancy between docstring and code:** The builder docstring says `(AT + MarketEquity - CEQ) / AT`, but the engine code computes `(cshoq * prccq + debt_book) / atq` where `debt_book = dlcq.clip(0).fillna(0) + dlttq.clip(0).fillna(0)`. These are algebraically different formulas. The code is the source of truth. Source: `_compustat_engine.py` lines 982-992 vs `tobins_q.py` docstring line 1.

7. **R2 and Adj R2 computation:** R2 is `model.rsquared` (overall R2 from PanelOLS). Adj R2 is computed manually as `1 - (1 - R2) * (nobs - 1) / df_resid` (runner line 400/413), not using PanelOLS's own adjusted R2 property.

8. **Analyst and sentiment variables in panel but not in H1.1:** The panel builder includes `AnalystQAUncertaintyBuilder` and `NegativeSentimentBuilder`, neither of which appear in the H1.1 regression specs. They are retained for other consumers of the shared H1 panel.
