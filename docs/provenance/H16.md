Model Family:    PanelOLS

Panel Index:     (gvkey, cal_yr) for cols 1-4, 7-10; (gvkey, cal_yr_qtr) for cols 5-6, 11-12
Columns:         12
Reference:       Jiang, John, and Larsen (2021)
Runner:          src/f1d/econometric/run_h16_rd_sales.py
Panel Builder:   src/f1d/variables/build_h16_rd_sales_panel.py

## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

**Contemporaneous (cols 1-6):**

$$
\text{RDSales}_{i,t} = \beta_1 \cdot \text{CEO\_QA\_Uncertainty\_pct} + \beta_2 \cdot \text{CEO\_Pres\_Uncertainty\_pct} + \beta_3 \cdot \text{Manager\_QA\_Uncertainty\_pct} + \beta_4 \cdot \text{Manager\_Pres\_Uncertainty\_pct} + \gamma' \mathbf{Controls} + \alpha_i + \delta_t + \varepsilon_{i,t}
$$

**Lead (cols 7-12):**

$$
\text{RDSales\_lead}_{i,t} = \beta_1 \cdot \text{CEO\_QA\_Uncertainty\_pct} + \beta_2 \cdot \text{CEO\_Pres\_Uncertainty\_pct} + \beta_3 \cdot \text{Manager\_QA\_Uncertainty\_pct} + \beta_4 \cdot \text{Manager\_Pres\_Uncertainty\_pct} + \gamma' \mathbf{Controls} + \alpha_i + \delta_t + \varepsilon_{i,t}
$$

Where $\alpha_i$ is entity FE (Industry FF12 or Firm) and $\delta_t$ is time FE (Calendar Year or Calendar Year-Quarter).

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| RDSales | R&D investment intensity (Jiang et al. 2021) | xrdy_annual (Q4 YTD) / saley_annual (Q4 YTD); missing xrd set to 0; nonpositive sales yield NaN; saley fallback to saleq when missing | CompustatEngine: xrdy, saley, saleq | Contemporaneous (t) |
| RDSales_lead | Next fiscal year's RDSales | For each (gvkey, fyearq_int), take RDSales from latest call within that fiscal year, shift -1 within gvkey to next fiscal year; NaN if fiscal years not consecutive | Derived from RDSales via fyearq shifting in panel builder | Lead (t+1 fiscal year) |

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| CEO_QA_Uncertainty_pct | CEO Q&A section uncertainty word percentage | (uncertainty word count / total word count) * 100 in CEO Q&A responses | LinguisticEngine | Contemporaneous (t) |
| CEO_Pres_Uncertainty_pct | CEO Presentation section uncertainty word percentage | (uncertainty word count / total word count) * 100 in CEO Presentation | LinguisticEngine | Contemporaneous (t) |
| Manager_QA_Uncertainty_pct | All-manager Q&A section uncertainty word percentage | (uncertainty word count / total word count) * 100 in Manager Q&A responses | LinguisticEngine | Contemporaneous (t) |
| Manager_Pres_Uncertainty_pct | All-manager Presentation section uncertainty word percentage | (uncertainty word count / total word count) * 100 in Manager Presentation | LinguisticEngine | Contemporaneous (t) |

No centering, log-transformation, or z-scoring is applied to the IVs.

### B4. Control Variables

**Base Controls (9, including Lagged_DV):**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| Size | Firm size | ln(atq); NaN if atq <= 0 | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + dlcq.clip(0).fillna(0) + dlttq.clip(0).fillna(0)) / atq; debt_book = NaN when BOTH dlcq and dlttq missing; NaN if atq missing/zero or mktcap missing | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets, where avg_assets = (atq_t + atq_{t-1}) / 2 | CompustatEngine: iby, atq |
| BookLev | Book leverage | (dlcq + dlttq) / atq; missing debt components filled with 0 | CompustatEngine: dlcq, dlttq, atq |
| CashHoldings | Cash holdings ratio | cheq / atq | CompustatEngine: cheq, atq |
| CapexAt | Capital expenditure intensity | capxy_annual (Q4 YTD) / atq_lag1_annual (prior fiscal year Q4 atq) | CompustatEngine: capxy, atq |
| DividendPayer | Dividend payer indicator | 1 if dvy_annual (Q4 YTD) > 0, else 0 | CompustatEngine: dvy |
| OCF_Volatility | Operating cash flow volatility | Rolling 5-year std (min 3 years) of (oancfy / atq_{t-1}) per gvkey, using Q4-only annual values joined to all quarters | CompustatEngine: oancfy, atq |
| Lagged_DV | Lagged dependent variable | For contemporaneous specs (cols 1-6): RDSales_lag (prior fiscal year's RDSales); for lead specs (cols 7-12): also RDSales_lag | Derived from RDSales via fyearq shifting |

NOTE: RD_Intensity is EXCLUDED from controls because the DV (RDSales) is R&D-based -- bad control (same numerator concept). See runner line 101.

**Extended Controls (= Base + 3 additional):**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| SalesGrowth | Sales growth | (saley_t - saley_{t-1}) / abs(saley_{t-1}); saley fallback to saleq when missing; gap years yield NaN | CompustatEngine (Biddle 2009): saley, saleq |
| CashFlow | Operating cash flow | oancfy / avg_assets, where avg_assets = (atq_t + atq_{t-1}) / 2; fallback to atq_t when atq_{t-1} missing | CompustatEngine (Biddle 2009): oancfy, atq |
| Volatility | Stock return volatility | std(daily_ret) * sqrt(252) * 100 over [prev_call_date + 5d, call start_date - 5d]; min 10 trading days | CRSPEngine: daily returns (RET) |

### B5. Fixed Effects / Stratification / Random Effects

| FE Type | Column Used | Description |
|---------|-------------|-------------|
| Entity (Industry) | ff12_code | Fama-French 12 industry dummies, absorbed via PanelOLS `other_effects` (odd columns) |

`cal_yr` and `cal_yr_qtr` are derived from `start_date` (call date), not fiscal year. `cal_yr_qtr = cal_yr * 10 + cal_qtr` where `cal_qtr = start_date.dt.quarter`.

Source: `build_cal_yr_qtr_index()` in `src/f1d/shared/variables/panel_utils.py` (line 195).

### B6. Standard Errors and Clustering

- **cov_type:** `"clustered"` with `cluster_entity=True`
- **Clustering dimension:** Entity (firm, gvkey)

Source: runner lines 372, 378.

### B7. Hypothesis Test

- **Direction:** Two-tailed (beta != 0); H16 makes no directional prediction
- **P-value computation:** Two-tailed p-values used directly from `model.pvalues` (no conversion)
- **Significance thresholds:** *** p<0.01, ** p<0.05, * p<0.10 (two-tailed)

   - 12 PanelOLS models, firm-clustered SEs, drop_absorbed=True
   - Industry FE specs: PanelOLS constructor with `other_effects=ff12_code`, `time_effects=True`
   - Firm FE specs: PanelOLS.from_formula with `EntityEffects + TimeEffects`

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

- **Level:** 1%/99% by fiscal year (fyearq) at CompustatEngine level
- **Function:** `_winsorize_by_year()` (CompustatEngine line 444), min 10 obs per year-group
- **Applied to:** All COMPUSTAT_COLS except DividendPayer (binary), CashFlow, SalesGrowth (already winsorized per-year inside `_compute_biddle_residual` -- do not double-winsorize), fqtr (fiscal quarter identifier), ExternalFunding (binary, H20 suite), and DebtChoice (binary, H20 suite). This includes: Size, TobinsQ, ROA, BookLev, CashHoldings, CapexAt, OCF_Volatility, RDSales
- **NOT applied to:** Linguistic IVs (CEO_QA_Uncertainty_pct, CEO_Pres_Uncertainty_pct, Manager_QA_Uncertainty_pct, Manager_Pres_Uncertainty_pct) -- bounded [0,100] by construction
- **NOT applied to:** Volatility (computed at CRSPEngine/builder level, not winsorized)
- **NOT applied to:** DividendPayer (binary 0/1)

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (per-spec in `prepare_regression_data`)
- Inf/-Inf replaced with NaN before regression (`df.replace([np.inf, -np.inf], np.nan)` at runner line 281)
- Also replaced at engine level: in the main `_compute_and_winsorize()` loop at line 1204, and inside ratio-computation helpers at lines 335 (OCF ratio), 621 (Investment), 646 (TobinsQ), 663 (SalesGrowth), 692 (CashFlow)
- Missing xrd (R&D expense) set to 0 in RDSales formula -- standard accounting convention (firms with no R&D expense report NaN, treated as 0)
- Nonpositive sales yield NaN for RDSales (excluded from analysis)

### H3. Transformations

- **Size:** Natural log of total assets (ln(atq))
- **DividendPayer:** Binary indicator (0/1 from continuous dvy)
- **RDSales lead/lag:** Fiscal-year-based shifting with consecutive-year validation (NaN for gaps)
- No other centering, z-scoring, or scaling applied

## L. KNOWN ISSUES AND NOTES

1. **RD_Intensity excluded from regressions and not used in Stage 4:** The panel builder imports and writes `RDIntensityBuilder` output to the Stage 3 parquet, but the runner excludes RD_Intensity from both BASE_CONTROLS and EXTENDED_CONTROLS because the DV is R&D-based (bad control, same numerator concept; runner line 101). RD_Intensity is **not loaded by the runner** (absent from `load_panel()` column selection at lines 219-231) and **not included in summary statistics** (absent from `SUMMARY_STATS_VARS` at lines 150-171). RD_Intensity is currently unused in Stage 4.

2. **Attrition table approximation:** The runner's attrition table (lines 814-821) uses col 1 N for the final step. Actual N varies per spec due to different DVs and control sets. The attrition table captures the general cascade but not per-column counts.

3. **RDSales construction -- missing R&D set to zero:** Following Jiang, John, and Larsen (2021) convention, missing xrdy is filled with 0 before dividing by sales. This means firms that do not report R&D expense are assigned RDSales = 0 rather than being excluded. This is documented at CompustatEngine line 977 (`xrd_for_rd = ... .fillna(0)`) and runner line 11.

4. **saley fallback to saleq:** The denominator for RDSales uses `saley` (annual total revenue YTD) with fallback to `saleq` (quarterly revenue) when saley is missing. This is consistent with the SalesGrowth computation (CompustatEngine line 976).

5. **fyearq attachment for lead/lag:** RDSales_lead and RDSales_lag are constructed using fiscal year (`fyearq_int`) via `attach_fyearq()` which does a merge_asof from call start_date to Compustat datadate. Calls with no matching Compustat quarter get NaN fyearq and therefore NaN lead/lag.

6. **Lagged_DV is always RDSales_lag:** For both contemporaneous and lead specs, `Lagged_DV` is assigned from `RDSales_lag` (prior fiscal year RDSales). This is constructed in `prepare_regression_data()` (runner line 265: `base_dv = dv.replace("_lead_qtr", "").replace("_lead", "")`), which strips the `_lead` suffix to get `RDSales`, then looks up `RDSales_lag`.

7. **cal_yr vs fyearq:** The FE time index uses calendar year/quarter from the call date (`cal_yr`, `cal_yr_qtr`), not fiscal year. The lead/lag construction uses fiscal year (`fyearq_int`) for correct within-firm shifting. These are distinct: a firm with a June fiscal year-end may have Q4 earnings calls in calendar Q3.
