## B. MODEL SPECIFICATION

### B1. Regression Equation

Both columns use the same moderation specification with Industry FE. Time FE varies.

$$
\text{CashHoldings}_{i,t} = \beta_1 \cdot \text{Manager\_QA\_Unc\_c}_{i,t}
+ \beta_2 \cdot \text{BelowIG}_{i,t}
+ \beta_3 \cdot \text{Unrated}_{i,t}
+ \beta_4 \cdot (\text{Manager\_QA\_Unc\_c}_{i,t} \times \text{BelowIG}_{i,t})
+ \beta_5 \cdot (\text{Manager\_QA\_Unc\_c}_{i,t} \times \text{Unrated}_{i,t})
+ \gamma \mathbf{X}_{i,t}
+ \alpha_{\text{Industry}(j)} + \delta_t + \varepsilon_{i,t}
$$

where:
- $\alpha_{\text{Industry}(j)}$ is absorbed via `other_effects` (FF12 industry code)
- $\delta_t$ is absorbed via `time_effects=True` (Calendar Year in Col 1; Calendar Year-Quarter in Col 2)
- Reference group: Investment-grade firms (both BelowIG=0 and Unrated=0)
- $\beta_1$ = uncertainty effect for IG firms (reference group alone)
- $\beta_4$ = differential uncertainty-cash sensitivity for below-IG firms (the key CH1 test)
- $\beta_5$ = differential uncertainty-cash sensitivity for unrated firms

Source: `run_h1_2_cash_constraint.py` lines 16-18 (docstring), lines 330-331 (interaction construction), lines 438-447 (PanelOLS instantiation).

**Moderator Construction (Three-Category, L1 fix):**
The moderator uses S&P long-term issuer credit ratings (`splticrm`) from Compustat Daily Ratings (monthly, 2000-01 to 2017-02). Ratings are matched to each call via `pd.merge_asof` (backward direction) on `(gvkey, start_date)` to avoid look-ahead bias (lines 225-234).

This three-category design separates genuinely credit-constrained firms (below-IG, ~23% of Main sample) from the heterogeneous unrated population (~52%), which were previously conflated in a binary moderator.

## L. KNOWN ISSUES AND NOTES

1. **Shared panel with H1:** H1.2 reuses the H1 cash holdings panel (Stage 3) and loads credit ratings only at Stage 4 in the runner. This means H1.2 does not have its own panel builder; the moderator variables are constructed on-the-fly.

2. **Year range restriction (2002-2016):** The sample is truncated to fiscal years 2002-2016 because Compustat Daily Ratings coverage ends in 2017-02 (runner docstring line 43, line 104). This drops calls from 2017-2018 that are available in the full H1 sample.

3. **IG_RATINGS definition:** The set of investment-grade ratings is hardcoded as `{"AAA", "AA+", "AA", "AA-", "A+", "A", "A-", "BBB+", "BBB", "BBB-"}` (line 100). This follows the standard S&P investment-grade boundary at BBB-.

4. **L1 fix context:** The three-category design (IG / Below-IG / Unrated) replaced a prior binary moderator that conflated below-IG firms (who hold less cash than IG: 0.102 vs 0.106) with unrated firms (who hold far more: 0.237). The binary moderator was mixing opposite signals (docstring lines 26-29).

5. **VIF diagnostics:** The runner computes and prints Variance Inflation Factors for the interaction terms and moderator dummies (`compute_vif()`, lines 363-384, called at line 427-432). These are saved in `model_diagnostics.csv` but not in the LaTeX table.

6. **CashHoldings not in summary stats as Lagged_DV:** Note that `SUMMARY_STATS_VARS` does not include `Lagged_DV` / `CashHoldings_lag`. The summary statistics are computed on the Main sample before the per-spec complete-case filter (line 808), so `Lagged_DV` has not yet been assigned from `CashHoldings_lag` at that point.

7. **CurrentRatio imported but not used:** The panel builder imports `CurrentRatioBuilder` and builds `CurrentRatio` (line 152), but the H1.2 runner does not include `CurrentRatio` in CONTROLS (lines 86-91). It is available in the panel but unused in this suite.

8. **Analyst and CEO linguistic variables built but unused:** The panel builder loads `AnalystQAUncertaintyBuilder`, `NegativeSentimentBuilder`, `CEOQAUncertaintyBuilder`, `CEOPresUncertaintyBuilder`, and `ManagerPresUncertaintyBuilder` (lines 124-140). H1.2 uses only `Manager_QA_Uncertainty_pct`. The other linguistic columns are present in the panel but unused by this runner.

9. **Adj R2 computed manually:** Adjusted R-squared is computed inline as `1 - (1 - model.rsquared) * (model.nobs - 1) / model.df_resid` (line 476, 491) rather than using a built-in property.

10. **Lagged DV unused in extra_controls code path:** The runner code at lines 468-470 has logic to extract `CashHoldings` beta when `"CashHoldings"` is in `extra_controls`, but `extra_controls` is always `[]` in both MODEL_SPECS (lines 107-108). This code path is dead for the current specification.

11. **TobinsQ formula: docstring vs code divergence.** The `tobins_q.py` builder docstring says `(AT + cshoq*prccq - CEQ) / AT`, but the actual code in `_compustat_engine.py` line 988-991 computes `(cshoq*prccq + debt_book) / atq` where `debt_book = dlcq.clip(0).fillna(0) + dlttq.clip(0).fillna(0)`. Per provenance rules, this document reports the code's formula. Both are standard Tobin's Q approximations; the code version uses market equity + book debt rather than the Chung-Pruitt (1994) variant in the docstring.
