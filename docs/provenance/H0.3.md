## A. SUITE IDENTITY

```yaml
Suite ID:        H0.3
Title:           Extended Controls Robustness -- CEO and Manager Clarity Fixed Effects
Hypothesis:      Does the addition of extended financial controls (Size, BM, BookLev,
                 ROA, CurrentRatio, RD_Intensity, Volatility) change the CEO fixed
                 effect estimates in Q&A uncertainty regressions?
Direction:       two-tailed (robustness check, not a hypothesis test)
Model Family:    OLS with categorical CEO and Year dummies
Estimator:       statsmodels.formula.api.ols (smf.ols)
Unit of Obs:     call-level (one row per earnings conference call)
Panel Index:     (ceo_id, year) -- via C(ceo_id) + C(year) dummy encoding
Columns:         4
Reference:       "--"
Runner:          src/f1d/econometric/run_h0_3_ceo_clarity_extended.py
```

## B. MODEL SPECIFICATION

### B1. Regression Equation

All four models follow the same structural form:

```
DV_{i,t} = b0 + sum_j(b_j * LinguisticControl_j) + sum_k(b_k * FirmControl_k)
           + alpha_CEO + gamma_year + epsilon_{i,t}
```

Where `alpha_CEO` is absorbed via `C(ceo_id)` dummy encoding and `gamma_year` via `C(year)` dummy encoding.

Exact statsmodels formula (line 369 of runner):

```
{dep_var} ~ C(ceo_id) + {controls} + C(year)
```

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| Manager_QA_Uncertainty_pct | Percentage of uncertainty words in Manager Q&A speech | (uncertainty_word_count / total_word_count) * 100 in Manager Q&A segments | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| CEO_QA_Uncertainty_pct | Percentage of uncertainty words in CEO Q&A speech | (uncertainty_word_count / total_word_count) * 100 in CEO Q&A segments | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |

- Columns 1-2 use Manager_QA_Uncertainty_pct as DV.
- Columns 3-4 use CEO_QA_Uncertainty_pct as DV.

### B3. Independent Variable(s)

This suite is a robustness check, not a standard 4-IV suite. There are no "key" independent variables in the hypothesis-testing sense. The linguistic controls serve as regressors alongside CEO FE; the purpose is to compare CEO FE stability across baseline vs. extended specifications.

The linguistic controls that vary by DV type:

| Variable Name (code) | Description | Applies To | Source Engine |
|---|---|---|---|
| Manager_Pres_Uncertainty_pct | Uncertainty % in Manager Presentation speech | Manager DV (cols 1-2) | LinguisticEngine |
| CEO_Pres_Uncertainty_pct | Uncertainty % in CEO Presentation speech | CEO DV (cols 3-4) | LinguisticEngine |
| Analyst_QA_Uncertainty_pct | Uncertainty % in Analyst Q&A speech | All models | LinguisticEngine |
| Entire_All_Negative_pct | Negative sentiment % across entire call | All models | LinguisticEngine |

### B4. Control Variables

**Base Firm Controls** (all 4 models):

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| StockRet | Compound stock return (%) over inter-call window | prod(1 + daily_RET) - 1, scaled to %; window = [call_date + 1 day, next_call_date - 5 days], min 10 trading days | CRSPEngine: RET |
| MarketRet | Compound value-weighted market return (%) over inter-call window | prod(1 + daily_VWRETD) - 1, scaled to %; same window as StockRet | CRSPEngine: VWRETD |
| EPS_Growth | Year-over-year EPS growth | (epspxq - lag_epspxq) / abs(lag_epspxq); lag identified by datadate arithmetic (target = datadate - 365 days, merge_asof backward, accept within +/-45 days) | CompustatEngine: epspxq |
| SurpDec | Earnings surprise decile (-5 to +5) | ACTUAL - MEANEST ranked within calendar quarter into signed decile scale | IbesEngine: ACTUAL, MEANEST from IBES Detail |

**Extended Controls** (models 2 and 4 only):

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| Size | Firm size (log total assets) | ln(atq); atq <= 0 yields NaN | CompustatEngine: atq |
| BM | Book-to-market ratio | ceqq / (cshoq * prccq) | CompustatEngine: ceqq, cshoq, prccq |
| BookLev | Book leverage (interest-bearing debt) | (dlcq.fillna(0) + dlttq.fillna(0)) / atq | CompustatEngine: dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets; avg_assets = (atq_t + atq_{t-1}) / 2 | CompustatEngine: iby, atq |
| CurrentRatio | Current ratio | actq / lctq; lctq == 0 yields NaN | CompustatEngine: actq, lctq |
| RD_Intensity | R&D intensity | xrdq.fillna(0) / atq | CompustatEngine: xrdq, atq |
| Volatility | Annualized stock return volatility (%) | std(daily_RET) * sqrt(252) * 100 over inter-call window; min 10 trading days | CRSPEngine: RET |

Note: No Lagged_DV is used in this suite. This is a CEO fixed effects robustness check, not a standard hypothesis suite.

### B5. Fixed Effects / Stratification / Random Effects

| FE Type | Column Used | Description | Method |
|---|---|---|---|
| Entity | ceo_id | CEO fixed effects | C(ceo_id) dummy variables in OLS formula |
| Time | year | Calendar year FE | C(year) dummy variables in OLS formula |

The `year` column is derived from `start_date.dt.year` in the panel builder (line 237 of builder). It is converted to string before regression (line 342 of runner) so that `C(year)` creates dummies.

### B6. Standard Errors and Clustering

- **Estimator:** `smf.ols` (statsmodels formula OLS)
- **cov_type:** `"cluster"` (line 380 of runner)
- **Clustering dimension:** CEO-level (`cov_kwds={"groups": df_reg["ceo_id"]}`, line 381)
- **Small-sample corrections:** statsmodels default for clustered SEs

### B7. Hypothesis Test

- **Direction:** Two-tailed. This is explicitly a robustness check (runner docstring lines 23-24: "This is a robustness check (not a hypothesis test)").
- **P-value computation:** Standard two-tailed p-values from statsmodels OLS output. No one-tailed conversion.
- **Significance thresholds:** *** p<0.01, ** p<0.05, * p<0.10 (standard in LaTeX table generation).
- **Interpretation:** Stability of CEO FE coefficient estimates between baseline and extended specifications, not directional hypothesis testing.

## H. OUTLIER AND MISSING DATA TREATMENT

### H1. Winsorization

| Variable Group | Level | Bounds | Applied By |
|---|---|---|---|
| Linguistic _pct variables | 0%/99% per year (upper-only) | lower=0.0, upper=0.99, min_obs=10 | LinguisticEngine._linguistic_engine.py line 255 |
| Compustat variables (Size, BM, BookLev, ROA, CurrentRatio, RD_Intensity, EPS_Growth) | 1%/99% per fiscal year (fyearq) | lower=0.01, upper=0.99, min_obs=10 | CompustatEngine._compustat_engine.py line 1134 |
| CRSP variables (StockRet, MarketRet, Volatility) | 1%/99% per calendar year | lower=0.01, upper=0.99, min_obs=10 | CRSPEngine._crsp_engine.py line 445 |
| SurpDec | Not winsorized | Discrete rank variable (-5 to +5) | -- |

### H2. Missing Data Policy

- **Complete-case deletion:** Rows dropped if any required variable is NaN for a given model (runner lines 278-279).
- **Inf/-Inf replaced with NaN:** At engine level before winsorization (CompustatEngine line 1110; CRSPEngine within winsorize_by_year).
- **R&D missing convention:** xrdq.fillna(0) -- missing R&D treated as zero per standard convention (CompustatEngine line 967).
- **Debt missing convention:** dlcq.fillna(0) + dlttq.fillna(0) -- missing debt components treated as zero (CompustatEngine line 943).

### H3. Transformations

| Variable | Transformation | Applied Where |
|---|---|---|
| 11 firm-level continuous controls (Size, BM, BookLev, ROA, CurrentRatio, RD_Intensity, Volatility, StockRet, MarketRet, EPS_Growth, SurpDec) | z-score standardization: (x - mean) / std within each model's estimation sample | Runner run_regression() lines 345-363 |
| Size | Natural log: ln(atq) | CompustatEngine line 938 |

The z-score standardization is applied at regression time for numerical stability (prevents SVD convergence issues with the large CEO dummy matrix), not at the panel-building stage. The standardization uses each model's own estimation sample mean/std, so coefficients are in standardized units.

### K5. OLS (non-panel) Specifics

- **Estimator:** `statsmodels.formula.api.ols` (smf.ols) -- runner line 379.
- **FE handling:** CEO fixed effects and Year fixed effects are implemented via `C(ceo_id)` and `C(year)` dummy variable encoding in the OLS formula (not absorbed). This means the dummy coefficients are explicitly estimated, creating a large design matrix.
- **HC robust SE type:** Clustered standard errors (`cov_type="cluster"`, `cov_kwds={"groups": df_reg["ceo_id"]}`). This is CEO-level clustering, consistent with the entity dimension.
- **Weighting:** None (unweighted OLS).
- **Formula construction:** `f"{dep_var} ~ C(ceo_id) + {controls} + C(year)"` (runner line 369). The intercept is implicit (statsmodels includes it by default with C() terms).
- **Numerical stability:** All continuous controls are z-score standardized within each model's estimation sample before fitting (runner lines 345-363). This prevents SVD convergence issues from the large CEO dummy matrix.
- **Residual extraction:** Baseline models (Manager_Baseline, CEO_Baseline) extract OLS residuals and save them as parquet files. These residuals are the "CEO clarity" residuals used by downstream hypothesis suites as independent variables (runner lines 395-406).
- **R-squared:** Both `model.rsquared` and `model.rsquared_adj` are reported in diagnostics. The generate_all_tables entry uses `$R^2$` (not within-R2) since this is OLS, not PanelOLS.

## L. KNOWN ISSUES AND NOTES

1. **Not a hypothesis test:** The docstring (lines 23-24) and the generate_all_tables entry both correctly classify this as a robustness check, not a directional hypothesis test. All key_tails are "two".

2. **Residual outputs are consumed downstream:** The `manager_clarity_residual.parquet` and `ceo_clarity_residual.parquet` outputs from baseline models (cols 1, 3) are consumed by `ManagerClarityResidualBuilder` and `CEOClarityResidualBuilder` in downstream hypothesis suites. The residual represents the CEO-specific component of Q&A uncertainty after controlling for linguistic context, firm characteristics, and time effects.

3. **z-score standardization at regression time:** Continuous controls are standardized per-model, per-run (runner lines 345-363). This means the regression coefficients are in standardized units and are not directly comparable to raw-unit coefficients in other suites. The standardization is applied to all 11 continuous variables (Size, BM, BookLev, ROA, CurrentRatio, RD_Intensity, Volatility, StockRet, MarketRet, EPS_Growth, SurpDec), including the DV's own controls.

4. **CEO FE via dummies, not absorbed:** Unlike standard hypothesis suites that use PanelOLS with absorbed entity effects, H0.3 uses `C(ceo_id)` dummies in OLS. This explicitly estimates one coefficient per CEO, which can be computationally expensive with many CEOs. The trade-off is that it enables direct extraction of CEO FE residuals.

5. **Min calls filter uses CEO, not firm:** The MIN_CALLS = 5 filter (runner line 140) is applied to `ceo_id` (line 327), not `gvkey`. This ensures each CEO has enough observations for a meaningful fixed effect estimate.

6. **Year column is calendar year from start_date:** The `year` column is derived from `start_date.dt.year` (builder line 237), representing the calendar year of the earnings call, not the fiscal year. This is converted to string (runner line 342) for dummy encoding.

7. **generate_all_tables.py uses `"type": "moderation"`:** Despite not being a moderation suite, H0.3 uses the "moderation" type in generate_all_tables.py. This is because the table layout (varying DVs and control blocks across columns) requires the moderation table generator rather than the standard 4-IV generator.

8. **skip_adj_r2 = True:** The generate_all_tables entry skips Adjusted R-squared in the output table, reporting only R-squared. The runner computes and stores both metrics in model_diagnostics.csv.

9. **Summary stats cover all three industry samples:** Although regressions run only on the Main sample, summary statistics are generated for Main, Finance, and Utility samples (runner lines 622-635).

10. **Linguistic variable winsorization is upper-only:** The LinguisticEngine applies 0%/99% winsorization (lower=0.0, upper=0.99), meaning only the upper tail is clipped. This is because linguistic percentages are bounded at 0 from below by construction. This differs from Compustat and CRSP variables which use symmetric 1%/99% winsorization.
