## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

```
DebtChoice_{i,t} = b1*CEO_QA_Uncertainty_pct + b2*CEO_Pres_Uncertainty_pct
                 + b3*Manager_QA_Uncertainty_pct + b4*Manager_Pres_Uncertainty_pct
                 + Controls + alpha_j + gamma_t + epsilon_{i,t}
```

Where:
- `alpha_j` = Industry (FF12) FE (odd columns) or Firm FE (even columns)
- `gamma_t` = Calendar Year FE (cols 1-4) or Calendar Year-Quarter FE (cols 5-6)
- `i` = individual earnings call, `t` = calendar year or calendar year-quarter
- LPM: binary DV estimated with OLS (PanelOLS), not logit/probit
- Sample restricted to ExternalFunding = 1 (external funders only)

### B2. Dependent Variable

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| DebtChoice | Binary: debt-only = 1, equity or dual = 0 | 1 if debt issuance >5% of lagged atq AND equity issuance <=5%; 0 if equity or dual issuance (NaN if internal) | CompustatEngine: dlcq, dlttq, sstky, prstkcy, atq | Contemporaneous (fiscal year T) |

**Construction detail** (from `_compustat_engine.py`, lines 1094-1178):

1. **Debt issuance** (balance sheet change): Total debt at Q4 = dlcq + dlttq (missing field treated as 0; both-NaN preserved as NaN). Annual debt change = Q4 total debt(T) - Q4 total debt(T-1). Debt issuance ratio = change / lagged total assets (atq at Q4 of T-1).

2. **Equity issuance** (cash flow statement): Net equity issuance = sstky(Q4) - prstkcy(Q4). Both are YTD cumulative Compustat fields; Q4 value gives full-year total. Equity issuance ratio = net equity / lagged total assets.

3. **Classification** (Leary & Roberts 2010, Table 3, p.341):
   - Debt-only (DebtChoice=1): debt ratio > 5% AND equity ratio <= 5%
   - Equity or Dual (DebtChoice=0): equity ratio > 5% (regardless of debt ratio); dual classified as equity per L&R convention
   - Internal (DebtChoice=NaN): neither ratio > 5% -- these are excluded from sample via ExternalFunding=1 restriction
   - Threshold constant: `_LR_THRESHOLD = 0.05` (engine line 1159)

4. **Code logic** (engine lines 1172-1178):
   ```python
   comp["DebtChoice"] = np.where(
       comp["ExternalFunding"] != 1.0,
       np.nan,
       np.where(_is_debt & ~_is_equity, 1.0, 0.0),
   )
   ```

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| CEO_QA_Uncertainty_pct | CEO Q&A uncertainty word percentage | (Uncertainty word count / total word count) * 100, CEO Q&A section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| CEO_Pres_Uncertainty_pct | CEO presentation uncertainty word percentage | (Uncertainty word count / total word count) * 100, CEO presentation section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| Manager_QA_Uncertainty_pct | All-manager Q&A uncertainty word percentage | (Uncertainty word count / total word count) * 100, all managers Q&A section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |
| Manager_Pres_Uncertainty_pct | All-manager presentation uncertainty word percentage | (Uncertainty word count / total word count) * 100, all managers presentation section | LinguisticEngine (Stage 2 outputs) | Contemporaneous (t) |

All four IVs are bounded [0, ~2.5] by construction (percentage of Loughran-McDonald uncertainty words). Winsorized per-year 0%/99% (upper-only) at LinguisticEngine level.

### B4. Control Variables

**Base Controls** (cols 1-2):

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| Size | Firm size | ln(atq), atq > 0 only | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + debt_book) / atq | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets | CompustatEngine: iby, atq |
| CapexAt | Capital expenditure intensity | capxy_annual (Q4) / atq_lag | CompustatEngine: capxy, atq |
| CashHoldings | Cash ratio | cheq / atq | CompustatEngine: cheq, atq |
| DividendPayer | Dividend payer indicator | 1 if dvy_annual (Q4) > 0, else 0 | CompustatEngine: dvy |
| OCF_Volatility | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of oancfy / atq_{t-1} | CompustatEngine: oancfy, atq |
| Lagged_DV | Lagged ExternalFunding | ExternalFunding_lag = previous fiscal year's ExternalFunding classification | CompustatEngine + fiscal year shift |

**Extended Controls** (cols 3-6): Base Controls plus:

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| SalesGrowth | Revenue growth | (saley_t - saley_{t-1}) / abs(saley_{t-1}), Q4 annual | CompustatEngine: saley, saleq (fallback) |
| RD_Intensity | R&D intensity | xrdq / atq, missing xrdq = 0 | CompustatEngine: xrdq, atq |
| CashFlow | Operating cash flow scaled | oancfy / avg_assets, avg = (atq_t + atq_{t-1})/2 | CompustatEngine: oancfy, atq |
| Volatility | Stock return volatility | std(daily_ret) * sqrt(252) * 100 over inter-call window | CRSPEngine: daily returns |

**BookLev explicitly excluded** (runner `BASE_CONTROLS`, lines 77-81): BookLev = (dlcq + dlttq) / atq shares the dlcq+dlttq numerator concept with the DV's debt issuance component. Including it would create a "bad control" problem. Confirmed absent from both `BASE_CONTROLS` and `EXTENDED_CONTROLS`. This is correct and differs from H19 (which includes BookLev and has it flagged as an issue).

**Lagged_DV detail**: In `prepare_regression_data()` (runner line 207), `Lagged_DV` is assigned from `ExternalFunding_lag`, NOT `DebtChoice_lag`. This is a deliberate choice: DebtChoice_lag is NaN for all firm-years where the prior year was internal financing (ExternalFunding=0 in year T-1), which would drop 13,289 additional calls (57% of the lagged DV coverage) and severely reduce sample size. ExternalFunding_lag is a suitable lagged DV because it captures the firm's prior financing regime.

### B5. Fixed Effects

| FE Type | Column Used | Description | Cols |

### B6. Standard Errors and Clustering

- `cov_type="clustered"`, `cluster_entity=True` (runner lines 286, 291)
- Clustering dimension: entity (gvkey) -- firm-clustered standard errors
- No small-sample correction beyond what PanelOLS applies by default

### B7. Hypothesis Test

- Direction: **two-tailed** -- the effect of uncertainty on debt vs equity choice is theoretically ambiguous (more uncertainty could push firms toward debt to avoid dilution, or toward equity to preserve financial flexibility)
- P-value computation (runner lines 316-319): two-tailed p-values used directly from PanelOLS output (`model.pvalues`). No one-tailed conversion.
- Significance thresholds: `***` p < 0.01, `**` p < 0.05, `*` p < 0.10 (runner `_sig_stars` function, lines 327-333)
- Verified manually: Col 1, CEO_Pres_Uncertainty_pct: beta = -0.04998, se = 0.01812, t = -2.7590, p_two (reported) = 0.0058057058, p_two (recomputed via scipy.stats.t) = 0.0058056906. **MATCHES.**

## H. OUTLIER AND MISSING DATA TREATMENT
------------------------------------------------------------------------

### H1. Winsorization

**Compustat controls**: 1%/99% per fiscal year (fyearq), applied at CompustatEngine level (`_compute_and_winsorize`, `_compustat_engine.py` lines 1225-1232).
- Applied to: Size, BookLev (not used here, but computed), TobinsQ, ROA, CapexAt, CashHoldings, RD_Intensity, OCF_Volatility
- NOT applied to: DividendPayer (binary), ExternalFunding (binary, in skip_winsorize), DebtChoice (binary, in skip_winsorize), CashFlow (already winsorized per-year inside Biddle residual pipeline), SalesGrowth (same), Volatility (CRSP, not in Compustat engine)

**Linguistic IVs**: 0%/99% per year (upper-only), applied at LinguisticEngine level.
- Applied to: all four _pct IV columns
- Rationale: lower bound is 0% by construction; only upper tail clipped

### H2. Missing Data Policy

- Complete-case deletion: rows dropped if any required variable is NaN (runner lines 226-227)
- Inf/-Inf replaced with NaN before regression (runner line 218)
- Missing R&D (xrdq) treated as zero per standard convention (CompustatEngine)
- Missing debt (dlcq, dlttq) treated as zero for classification numerator; but both-NaN = NaN for classification (engine lines 1110-1112)
- CEO IV coverage: 16,328/23,289 (70.1%) in external funders -- CEO-level IVs are the primary cause of sample attrition (10,047 calls lost before min-calls filter)
- ExternalFunding_lag coverage: 21,181/23,289 (90.9%) in external funders -- missing at panel boundaries

### H3. Transformations

- Size: natural log of total assets (ln(atq))
- Volatility: annualized (multiply by sqrt(252)) and expressed as percentage (* 100)
- No centering, z-scoring, or other transformations applied to IVs or other controls

### K1. PanelOLS Specifics (LPM)

**Methodological justification** (runner docstring lines 28-29):
- Timoneda (2021, Social Science Research): Monte Carlo evidence shows LPM-FE outperforms logit at base rates <5%.

**AUDIT NOTE**: The Timoneda (2021) justification is **doubly misapplied** to this suite. The DebtChoice base rate is **72.52%** (16,889 debt-only / 23,289 external funders). This is **over 14x** the <5% threshold where Timoneda's Monte Carlo evidence applies. Moreover, the base rate is highly asymmetric in the opposite direction from what Timoneda studies (rare events): 72.52% is near-universal, meaning equity/dual issuance is the rare event (27.48%). At 72.52% base rate, Var(p) = 0.7252 * 0.2748 = 0.1993 -- near-maximal heteroscedasticity. See Issue #1.

### Issue #1: Timoneda (2021) LPM Justification is Severely Misapplied [MAJOR]

**Severity**: Major (methodological justification error)

The runner's docstring cites Timoneda (2021) to justify using LPM over logit, specifically claiming "LPM-FE outperforms logit at base rates <5%." However, the DebtChoice base rate is **72.52%** -- over **14x** the <5% threshold where Timoneda's Monte Carlo evidence applies. This is not a marginal violation; the base rate is in the opposite extreme from what the citation supports.

At 72.52% base rate:
- Heteroscedasticity is near-maximal: Var(p) = p(1-p) = 0.1993 (maximum possible is 0.25 at p=0.5)
- Fitted probabilities outside [0,1] are plausible for observations in the tails of the covariate distribution
- Logit provides a natural bounding to [0,1] and correct heteroscedasticity structure

The LPM may still be defensible on OTHER grounds:
- Angrist & Pischke (2009, "Mostly Harmless Econometrics") argue LPM is generally acceptable when interest centers on average marginal effects
- With firm FE (even columns), the incidental parameters problem makes conditional logit difficult
- LPM coefficients are directly interpretable
- Horrace & Oaxaca (2006) show LPM predictions outside [0,1] do not bias coefficient estimates at means

**Recommendation**: Replace the Timoneda citation with Angrist & Pischke (2009) or note that the justification applies primarily to the firm-FE specifications (where conditional logit faces the incidental parameters problem). Optionally add a logit robustness check for the industry-FE specifications.

### Issue #2: Complete Sign Reversal Between Industry FE and Firm FE for Three IVs [MAJOR]

**Severity**: Major (identification and robustness concern)

Three of four IVs show **complete sign reversals** between industry FE (odd columns) and firm FE (even columns):

| IV | Industry FE sign | Firm FE sign | Pattern |
|---|---|---|---|
| CEO_QA_Uncertainty_pct | Negative (all 3) | Negative (all 3) | Consistent (but never significant) |
| CEO_Pres_Uncertainty_pct | **Negative** (all 3, significant at p<0.05) | **Positive** (all 3, never significant) | **Complete reversal** |
| Manager_QA_Uncertainty_pct | **Positive** (all 3, significant at p<0.05) | Positive (all 3, never significant) | Consistent sign, significance vanishes |
| Manager_Pres_Uncertainty_pct | **Positive** (all 3, significant at p<0.05) | **Negative** (all 3, never significant) | **Complete reversal** |

CEO_Pres_Uncertainty_pct: -0.0500*** (Col 1) vs +0.0081 (Col 2). The sign flips from significantly negative under industry FE to positive (and insignificant) under firm FE. This means the effect is driven ENTIRELY by between-firm variation (firms in different industries with different CEO presentation uncertainty levels have different debt choice patterns), not within-firm variation.

Manager_Pres_Uncertainty_pct: +0.0476** (Col 1) vs -0.0159 (Col 2). Same reversal pattern.

**Implication**: The industry-FE results may reflect OMITTED VARIABLE BIAS from industry-level confounders rather than a causal effect of uncertainty on debt choice. When firm FE absorb time-invariant firm characteristics (including persistent industry membership), all significance vanishes and two IVs reverse sign. This is a classic "between effect vs within effect" diagnostic suggesting the cross-sectional correlation is spurious.

A skeptical referee would argue that the industry-FE results are driven by the composition of industries in the external-funders subsample -- industries with inherently more uncertain speech (e.g., tech) may also have structurally different debt vs equity patterns for reasons unrelated to uncertainty.

### Issue #3: Suspicious 3x Coefficient Jump from Base to Extended Controls [MODERATE]

**Severity**: Moderate (suppression / omitted variable diagnostic)

Manager_QA_Uncertainty_pct coefficient jumps from 0.0481 (Col 1, base) to 0.1366 (Col 3, extended) -- a **2.84x increase** -- upon adding SalesGrowth, RD_Intensity, CashFlow, and Volatility to the industry-FE specification. Similarly, Manager_Pres_Uncertainty_pct jumps from 0.0476 to 0.1070 (2.25x).

This pattern is characteristic of a suppression effect: the extended controls are negatively correlated with both the IV and the DV, so including them "uncovers" a larger positive association. Empirically verified:
- Corr(Manager_QA, RD_Intensity) = +0.039, Corr(DebtChoice, RD_Intensity) = -0.334
- Corr(Manager_QA, Volatility) = +0.107, Corr(DebtChoice, Volatility) = -0.256

When the suppressed confounders are included, the residual variation in Manager_QA is more "purified" and the coefficient inflates. This is technically valid (adding relevant controls improves estimation) but the 3x magnitude change is a RED FLAG for model sensitivity. A small perturbation in the control set produces a large change in the IV coefficient, undermining confidence in any specific point estimate.

The sample size drops by only 556 calls (4.2%) from base to extended, ruling out composition effects.

### Issue #4: Negative Adjusted R-squared in All Firm FE Specifications [MODERATE]

**Severity**: Moderate (model diagnostics concern)

All three firm FE columns (2, 4, 6) have negative Adjusted R-squared:
- Col 2: R2 = 0.0436, Adj R2 = -0.0328
- Col 4: R2 = 0.0486, Adj R2 = -0.0297
- Col 6: R2 = 0.0516, Adj R2 = -0.0308

Negative Adj R2 means the model's 953 firm fixed effects consume more degrees of freedom than they explain in variance. The model is WORSE than predicting the sample mean for every observation after penalizing for complexity. The firm FE absorb nearly all of the modest overall R2 (0.04-0.05), and the covariates add essentially nothing beyond firm identity.

Combined with Issue #2 (all IVs become insignificant under firm FE), this strongly suggests that debt vs equity choice is overwhelmingly determined by persistent firm characteristics, and within-firm temporal variation in speech uncertainty has negligible explanatory power.

### Issue #5: Look-Ahead Bias in Contemporaneous DV [MODERATE]

**Severity**: Moderate (temporal alignment concern)

DebtChoice is an ANNUAL classification computed from Q4 (fiscal year-end) data -- specifically Q4 values of dlcq, dlttq, sstky, and prstkcy. However, this classification is assigned to ALL calls within the same fiscal year, including Q1, Q2, and Q3 calls that occur BEFORE the fiscal year's financing activity is complete.

For a call in Q1 of fiscal year T, the DV DebtChoice uses data from Q4 of fiscal year T, which will not be available until 6-9 months after the call. This means the "contemporaneous" DV actually incorporates future information relative to the call date.

This is more problematic for H20 than for H19 because:
- H20 has NO lead DV specification (unlike H19 which has cols 7-12 with ExternalFunding_lead)
- The entire suite is based on the contemporaneous annual classification
- The temporal direction of causality is ambiguous: is speech uncertainty causing debt choice, or does an already-decided financing plan affect what managers say?

**Recommendation**: Consider adding a lead DV specification (DebtChoice_lead = next fiscal year's debt choice among external funders) to provide a cleaner temporal test. This would require additional handling since DebtChoice_lead is NaN when the firm is not an external funder in the next year.

### Issue #6: Annual DV in Call-Level Panel Inflates Apparent N [MODERATE]

**Severity**: Moderate (inference concern)

The DV is a firm-year level variable (same value for all calls in a fiscal year; verified: 0 firm-years with inconsistent DebtChoice). The reported N of 13,242 (Col 1) represents individual calls, but only **3,639** unique firm-years. The inflation factor is **3.64x**.

This means:
- The regression is estimating an annual outcome from call-level covariates, with ~3.64 calls per firm-year contributing the SAME DV value
- Within-firm-year variation in IVs does not contribute to identification for the DV (all calls in a fiscal year share the same DebtChoice)
- The standard errors are clustered at the firm level (which partially accounts for within-firm correlation), but the effective degrees of freedom may be overstated because the DV has less variation than the N suggests
- Panel index duplicates: 14,090 duplicate (gvkey, cal_yr) entries; 1,111 duplicate (gvkey, cal_yr_qtr) entries (expected for call-level panel)

**Recommendation**: Report the effective firm-year count alongside the call count. Consider whether a firm-year level regression (averaging IVs within firm-year) would be more appropriate as a robustness check.

### Issue #7: Lagged_DV = ExternalFunding_lag Is Conceptually Imprecise [MINOR]

**Severity**: Minor (methodological nuance)

The Lagged_DV for H20 is ExternalFunding_lag (whether the firm was an external funder in the prior year), not DebtChoice_lag (whether the firm chose debt in the prior year). This choice is JUSTIFIED by the pragmatic concern that DebtChoice_lag would drop 13,289 calls (57% of lagged DV coverage) because DebtChoice is NaN for internal funders.

However, the conceptually correct lagged DV for a debt-choice model is the prior year's debt choice, not the prior year's external funding status. ExternalFunding_lag captures persistence in the funding regime but not in the debt-vs-equity composition. The lagged DV coefficient is significantly negative (around -0.08), meaning prior-year external funding REDUCES debt-choice probability, which has a counterintuitive interpretation: firms that used external funding last year are less likely to choose debt-only this year. This could reflect mean-reversion in financing mix rather than true state dependence.

### Issue #8: H20 Has No Lead DV Unlike H19 [MINOR]

**Severity**: Minor (design asymmetry)

H19 has 12 columns with both contemporaneous (ExternalFunding) and lead (ExternalFunding_lead) DVs. H20 has only 6 columns with the contemporaneous DebtChoice -- no lead specification. Given the look-ahead bias concern (Issue #5), a lead DV would strengthen identification.

The panel builder DOES create DebtChoice_lead (builder line 218-219), so the variable is available. The likely reason for omission is that DebtChoice_lead requires the firm to also be an external funder in year T+1, which would further restrict the already-restricted sample (ExternalFunding=1 in both T and T+1).

### Issue #9: LaTeX Table Omits Control Coefficients [MINOR]

**Severity**: Minor (formatting concern)

The LaTeX table (`_save_latex_table`) shows only the four IV coefficient rows. Per the project convention documented in `feedback_table_format.md`, the standard academic format requires "all controls shown." The 8 base controls and 4 extended controls are not displayed. Only "Controls: Base/Extended" and "Lagged DV: Yes" indicator rows are shown.

Full control coefficients are available in the individual `regression_results_col*.txt` files.

### Issue #10: High IV Multicollinearity [INFORMATIONAL]

**Severity**: Informational

The four IVs exhibit substantial pairwise correlations in the external funders sample:
- CEO_QA / Manager_QA: r = 0.767 (very high)
- CEO_Pres / Manager_Pres: r = 0.638 (high)

Including all four simultaneously makes individual IV coefficients unstable and reduces power for each. This is a design choice (simultaneous inclusion allows separating CEO vs management and Q&A vs presentation channels) but inflates standard errors and makes it harder to detect individual effects. The high CEO_QA/Manager_QA correlation (0.767) means these two are nearly collinear -- changes in one are largely captured by the other.

### Issue #11: Fiscal Year vs Calendar Year Mismatch [INFORMATIONAL]

**Severity**: Informational

24.56% of calls in the external funders sample have calendar year != fiscal year (5,719 mismatches). The DV is defined by fiscal year (DebtChoice for fiscal year T), but time FE use calendar year from start_date. This means firms with non-December fiscal year-ends have their DV defined in fiscal-year space but FE absorption in calendar-year space. This is a standard tension in call-level panels and is handled consistently across all suites.
