## B. MODEL SPECIFICATION
------------------------------------------------------------------------

### B1. Regression Equation

$$
\text{DSPREAD}_{i,t} = \beta_1 \cdot \text{CEO\_QA\_Unc} + \beta_2 \cdot \text{CEO\_Pres\_Unc} + \beta_3 \cdot \text{Mgr\_QA\_Unc} + \beta_4 \cdot \text{Mgr\_Pres\_Unc} + \gamma' \mathbf{Controls} + \alpha_i + \delta_t + \varepsilon_{i,t}
$$

Where $\alpha_i$ is entity FE (Industry FF12 or Firm) and $\delta_t$ is time FE (Calendar Year or Calendar Year-Quarter).

All four IVs enter simultaneously in every specification (horse-race design).

### B2. Dependent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| DSPREAD | Change in relative bid-ask spread around earnings call | mean(RelSpread[+1,+3]) - mean(RelSpread[-3,-1]) where RelSpread_d = 2*(ASK_d - BID_d)/(ASK_d + BID_d) using closing BID/ASK quotes | CRSPEngine via BidAskSpreadChangeBuilder | Event-window: [-3,-1] pre vs [+1,+3] post trading days around call |

Construction detail (from `bidask_spread_change.py`):
1. Map each call to PERMNO via date-bounded CCM linkage (linkdt <= start_date <= linkenddt).
2. Find reference date: last trading day on or before call start_date.
3. Pre-window: 3 nearest trading days before reference date (pre_rank 1-3).
4. Post-window: 3 nearest trading days after reference date (post_rank 1-3).
5. Compute closing spread per day: `spread_closing = 2 * (ASK - BID) / (ASK + BID)`.
6. Pre average = mean(spread_closing over pre-window), Post average = mean(spread_closing over post-window).
7. `delta_spread_closing = Post average - Pre average`.
8. Minimum 2 valid trading days required in each window (min_pre = min_post = max(1, window_days - 1) = 2).
9. Panel builder renames `delta_spread_closing` to `DSPREAD` (line 181 of panel builder).

### B3. Independent Variable(s)

| Variable Name (code) | Description | Formula | Source Engine | Timing |
|---|---|---|---|---|
| CEO_QA_Uncertainty_pct | CEO Q&A section uncertainty percentage | Percentage of uncertainty words in CEO's Q&A responses | LinguisticEngine | Contemporaneous (call-level) |
| CEO_Pres_Uncertainty_pct | CEO Presentation section uncertainty percentage | Percentage of uncertainty words in CEO's presentation | LinguisticEngine | Contemporaneous (call-level) |
| Manager_QA_Uncertainty_pct | Manager Q&A section uncertainty percentage | Percentage of uncertainty words in all managers' Q&A responses | LinguisticEngine | Contemporaneous (call-level) |
| Manager_Pres_Uncertainty_pct | Manager Presentation section uncertainty percentage | Percentage of uncertainty words in all managers' presentation | LinguisticEngine | Contemporaneous (call-level) |

All four IVs are bounded [0, 100] by construction. No winsorization is applied to linguistic IVs.

### B4. Control Variables

**Base Controls (8 variables):**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| Size | Firm size | ln(atq) | CompustatEngine: atq |
| TobinsQ | Tobin's Q | (cshoq * prccq + dlcq + dlttq) / atq | CompustatEngine: cshoq, prccq, dlcq, dlttq, atq |
| ROA | Return on assets | iby_annual (Q4) / avg_assets where avg_assets = (atq_t + atq_{t-1})/2 | CompustatEngine: iby, atq |
| BookLev | Book leverage | (dlcq + dlttq) / atq (missing debt treated as zero) | CompustatEngine: dlcq, dlttq, atq |
| CapexAt | Capital expenditure intensity | capxy_annual (Q4) / atq_{t-1} | CompustatEngine: capxy, atq |
| DividendPayer | Dividend payer indicator | 1 if dvy_annual (Q4) > 0, else 0 | CompustatEngine: dvy |
| OCF_Volatility | Operating cash flow volatility | Rolling 5-year std (min 3 yrs) of oancfy / atq_{t-1} per gvkey | CompustatEngine: oancfy, atq |
| PreCallSpread | Pre-call relative spread level (lagged-DV control) | mean(RelSpread[-3,-1]) using closing BID/ASK quotes | CRSPEngine via BidAskSpreadChangeBuilder |

**Extended Controls (Base + 4 additional):**

| Variable Name (code) | Description | Formula | Source Engine |
|---|---|---|---|
| StockPrice | Stock price at call date | abs(PRC) on call date or nearest prior trading day | CRSPEngine via StockPriceBuilder |
| Turnover | Share turnover at call date | VOL / (SHROUT * 1000) on call date or nearest prior trading day | CRSPEngine via TurnoverBuilder |
| Volatility | Return volatility | std(daily RET) * sqrt(252) * 100 over inter-call window (min 10 trading days) | CRSPEngine via VolatilityBuilder |
| AbsSurpDec | Absolute earnings surprise decile | abs(SurpDec) where SurpDec is ACTUAL - MEANEST ranked into [-5, +5] within quarter | IbesEngine via EarningsSurpriseBuilder |

Note: PreCallSpread serves as the lagged-DV control. It is the pre-call average relative bid-ask spread from the [-3,-1] trading day window, constructed from the same BidAskSpreadChangeBuilder as the DV.

### B5. Fixed Effects

| FE Type | Column Used | Description | Applicable Cols |
|---|---|---|---|
| Industry | ff12_code (via `other_effects`) | Fama-French 12 industry classification, absorbed via PanelOLS `other_effects` | Cols 1, 3, 5 |
| Firm | gvkey (via `EntityEffects`) | Firm fixed effects, absorbed via PanelOLS entity_effects | Cols 2, 4, 6 |
| Calendar Year | cal_yr (panel time index) | Calendar year FE, absorbed via PanelOLS `time_effects=True` | Cols 1, 2, 3, 4 |
| Calendar Year-Quarter | cal_yr_qtr (panel time index) | Calendar year-quarter FE (cal_yr * 10 + cal_qtr), absorbed via PanelOLS `time_effects=True` | Cols 5, 6 |

`cal_yr` and `cal_yr_qtr` are derived from `start_date` (call date) via `build_cal_yr_qtr_index()` in `panel_utils.py` (line 195-218). These are calendar, not fiscal, time indices.

### B6. Standard Errors and Clustering

- **cov_type:** `"clustered"`
- **Clustering dimension:** `cluster_entity=True` (firm-level, gvkey)
- **Source:** `run_h14_bidask_spread.py` lines 330, 335.

Both industry-FE and firm-FE specifications use identical clustering: `model_obj.fit(cov_type="clustered", cluster_entity=True)`.

### B7. Hypothesis Test

- **Direction:** one-tailed (beta > 0)
- **Interpretation:** Higher uncertainty -> larger increase in bid-ask spreads (reduced liquidity)
- **P-value computation:** `p_one = p_two / 2 if beta > 0 else 1 - p_two / 2` (runner line 364)
- **Significance thresholds:** `***` p < 0.01, `**` p < 0.05, `*` p < 0.10 (runner `_sig_stars`, line 384-394)

## F. DATA PIPELINE
------------------------------------------------------------------------

### F1. Dependency Chain

1. **Raw inputs:**
   - `inputs/CRSP_DSF/CRSP_DSF_{year}_Q{1-4}.parquet` (daily stock data with BID, ASK, BIDLO, ASKHI, PRC, VOL, SHROUT, RET, VWRETD)
   - `inputs/CRSPCompustat_CCM/CRSPCompustat_CCM.parquet` (PERMNO-GVKEY linkage)
   - `inputs/CompustatNA/compustat_na_quarterly.parquet` (Compustat quarterly fundamentals)
   - `outputs/2_Textual_Analysis/2.2_Variables/latest/` (linguistic uncertainty measures)
   - `outputs/1.4_AssembleManifest/latest/master_sample_manifest.parquet` (call manifest)
   - IBES detail/summary files (for earnings surprise)

2. **Engine loading:**
   - CRSPEngine: loads raw daily CRSP via `get_raw_daily_data()` (for DV, StockPrice, Turnover); loads computed returns/volatility via `get_data()` (for Volatility)
   - CompustatEngine: loads Compustat quarterly, computes all fundamental variables, winsorizes per fiscal year
   - LinguisticEngine: loads textual analysis output, provides uncertainty percentages
   - IbesEngine: loads IBES consensus, computes surprise_raw

3. **Panel builder** (`build_h14_bidask_spread_panel.py`):
   - Loads manifest (file_name, gvkey, start_date, ff12_code)
   - Loads all 16 builders (4 IVs, 7 Compustat controls, 3 CRSP controls, 1 DV/lagged-DV, 1 earnings surprise)
   - Merges each builder's output to manifest on `file_name` (left join, zero row-delta enforced)
   - Renames `delta_spread_closing` -> `DSPREAD`, `pre_call_spread_closing` -> `PreCallSpread`
   - Computes `AbsSurpDec = abs(SurpDec)`
   - Attaches fiscal year-quarter (`fyearq_int`) via `attach_fyearq()`
   - Builds calendar year-quarter index via `build_cal_yr_qtr_index()` (done in runner)
   - Winsorizes 5 CRSP-derived columns at 1%/99% pooled
   - Assigns industry sample (Main/Finance/Utility)
   - Saves parquet panel

4. **Runner loading** (`run_h14_bidask_spread.py`):
   - Loads panel from latest Stage 3 output
   - Selects required columns (line 196-209)
   - Builds `cal_yr_qtr` index via `build_cal_yr_qtr_index()`

5. **Sample filtering:**
   - Main sample filter: exclude ff12_code in {8, 11}
   - Per-spec: DV non-null -> complete case -> min 5 calls per firm

6. **Regression estimation:**
   - PanelOLS with firm-clustered SEs for each of 6 MODEL_SPECS
   - One-tailed p-values computed per IV

7. **Table generation:**
   - Runner writes its own LaTeX table (`_save_latex_table`)
   - Also listed in `outputs/generate_all_tables.py` as standard 4-IV suite

## K. MODEL-FAMILY ADDENDUM

### K1. PanelOLS Specifics

**Industry FE specs (cols 1, 3, 5):**
- Entity effects: NOT used (`entity_effects=False`)
- Time effects: Absorbed (`time_effects=True`)
- Industry FE: Absorbed via `other_effects=df_panel["ff12_code"]` (runner lines 321-329)
- `drop_absorbed=True` (runner line 328)
- `check_rank=False` (runner line 329)
- SE: `model_obj.fit(cov_type="clustered", cluster_entity=True)` (runner line 330)

**Firm FE specs (cols 2, 4, 6):**
- Entity effects: Absorbed via `EntityEffects` in formula (runner line 333)
- Time effects: Absorbed via `TimeEffects` in formula (runner line 333)
- Formula construction: `"{dv} ~ 1 + {exog_str} + EntityEffects + TimeEffects"` (runner line 333)
- `drop_absorbed=True` (runner line 334)
- SE: `model_obj.fit(cov_type="clustered", cluster_entity=True)` (runner line 335)

**Time index construction:**
- Cols 1-4: Panel index = `(gvkey, cal_yr)` where `cal_yr = start_date.dt.year` (runner line 304, 314)
- Cols 5-6: Panel index = `(gvkey, cal_yr_qtr)` where `cal_yr_qtr = cal_yr * 10 + cal_qtr` (runner line 304, 314)

**R-squared reporting:**

## L. KNOWN ISSUES AND NOTES

1. **Panel builder docstring mentions fyearq_int as time FE, but runner uses cal_yr / cal_yr_qtr.** The panel builder (line 34) refers to "FiscalYear FE (fyearq_int)" and attaches `fyearq_int` at line 195-197. However, the runner uses `cal_yr` (derived from start_date) and `cal_yr_qtr` as the actual time index for PanelOLS (runner line 304). The `fyearq_int` column is loaded by the runner (line 199) but never used as a panel index or FE dimension. **Code is the source of truth: the actual time FE is Calendar Year / Calendar Year-Quarter.**

2. **BidAskSpreadChangeBuilder computes both high-low spread and closing spread.** The builder computes two variants: `delta_spread` (using ASKHI/BIDLO high-low spread) and `delta_spread_closing` (using ASK/BID closing quotes). The panel builder renames only the closing variant to `DSPREAD` (line 180-183), which is the correct Lee (2016) construction using closing quotes. The high-low variant columns are discarded by the rename/column-selection logic.

3. **Placebo DV computed but unused.** The BidAskSpreadChangeBuilder computes a `pre_spread_change` column (spread on day -1 minus spread on day -3; builder lines 439-448) as a placebo test variable. This column is carried through but does not appear in any regression spec.

4. **Volatility comes from a different CRSPEngine method than other CRSP variables.** StockPrice, Turnover, and DSPREAD/PreCallSpread use `CRSPEngine.get_raw_daily_data()` (raw daily records). Volatility uses `CRSPEngine.get_data()` which computes inter-call window returns/volatility. The two methods have separate caches (`_cache` vs `_raw_cache`) and different winsorization strategies (per-year for Volatility via get_data, pooled for the others via panel builder).

5. **Double winsorization potential for Volatility.** Volatility is winsorized per-year at 1%/99% inside CRSPEngine.get_data() (engine level). It is NOT in the `winsorize_cols` list at panel builder line 202, so it avoids double winsorization. This is correct behavior per the panel builder comment at line 201: "Volatility is already winsorized per-year by CRSPEngine."

6. **AbsSurpDec construction.** SurpDec is computed within-quarter using `_rank_surprises` which maps raw earnings surprises (ACTUAL - MEANEST) to a [-5, +5] integer scale. AbsSurpDec = abs(SurpDec), producing a [0, 5] ordinal magnitude variable. This is then winsorized at 1%/99% pooled.

7. **PreCallSpread as lagged-DV control.** PreCallSpread (the pre-call average relative spread) functions as the lagged-DV control for this suite. It controls for the level of bid-ask spread before the call, isolating the change attributable to the call's information content.

8. **fyearq_int included in complete-case required list despite not being a FE column.** The runner's `prepare_regression_data` (line 241) includes `fyearq_int` in the `required` list used for complete-case filtering. However, `fyearq_int` is never used as a panel index or FE dimension (cal_yr and cal_yr_qtr are used instead). This causes rows with missing fiscal year mappings (from Compustat) to be dropped unnecessarily, potentially reducing sample size slightly.

9. **Runner docstring says "4 columns" but code has 6 MODEL_SPECS.** The runner docstring (line 11) states "4 columns in one table" and the Outputs section (line 46) lists `regression_results_col{1-4}.txt`, but the actual `MODEL_SPECS` list contains 6 entries generating col{1-6} outputs. The provenance document correctly documents 6 columns following the code-is-truth principle; the docstring is stale.
